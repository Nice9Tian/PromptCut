## 一、裁决依据与核心对齐规则

本次对齐以 `docs/plan/user-decisions-2026-10-14.md` 为最高优先级，全面推翻 10-13 冲突项与历史旧方案：

1. **名词规范（1.1）**：
   - 项目变更计数、历史状态步进严格统一为**「历史序号」**（推翻混用「版本」「版本号」）。
   - 卡片代码实现版本、软件发布版本严格保留为**「版本号」**。
2. **快照术语（1.2）**：
   - 区分**「HTML 快照」**（DOM 字符串，撤销单卡 HTML 快照，保留整场景 HTML 快照用于跨源舞台像素抓取）。
   - 将 `bake_card` 产物及单卡画面位图正式定名为**「PNG 快照」**。
3. **预渲染产流与开关（2.1）**：
   - 项目设置中的「生成轨道流」开关关着时，托管方什么都不产。
   - 开关开着且当前设备是桌面版由桌面版产；开着且当前设备是浏览器由托管方渲染服务产。
   - 该开关属于项目级策略配置，需要拥有者或管理员权限组方可操作。
4. **在线浏览器导出（2.2）**：
   - 在线浏览器导出在跨源隔离舞台里整帧渲染（所有卡+素材画到画布上取像素传给导出页压视频）。
   - 彻底废除等待渲染节点出导出位图的既有主路径，导出位图仅保留为极端情况下的退路。
5. **任务切分长度与强设备抢占（2.3）**：
   - 任务切分：素材移动/动效（如粒子、运镜等）按不少于 30 秒（900 帧）切一大段；Remotion 卡切成 8 段（约 4 秒一段）。
   - 抢占优先级：`桌面版 > 托管渲染服务 > 浏览器`。强设备认领大段后，若桌面版上线则优先抢占未开始分段。
6. **舞台跨源隔离与桌面舞台闸门（2.4）**：
   - 在线浏览器舞台强制跨源隔离（两独立 iframe 实例），彻底废除 20 秒/退回同源单舞台的妥协分支。
   - 桌面版舞台强制加闸门隔离，禁止卡片代码访问本地后端预渲染/编辑器 API 及跨项目素材。
7. **画布卡直接取像素（2.5）**：
   - 画布卡（粒子、`particles-*`、`scene-3d`、探针卡等）产流时一律直接从 `<canvas>` 读像素送编码，**不再逐段跑自动实测比对**，省去比对耗时与截图开销。
8. **bake_card 与 3D 视图贴图（2.6）**：
   - 播放时贴流（稀疏流、左对齐，未就绪时显示占位符；3D 模式轻卡亦产流，纹理随时间动）。
   - 暂停时回到精确活渲，导出时全精度活渲；单卡画面位图正式统一称为「PNG 快照」。
9. **账号与服务连接生命周期（3.0.1）**：
   - **推翻原 90 秒定时轮询续期机制**。
   - 已建立的账号连接与内部服务连接不因时间流逝或定时轮询而主动失效。
   - 失效（改密退出、踢出等）由账号服务主动向各服务推送带握手确认的事件通知，网络抖动或失败时指数退避重试最多 15 次，重连后错过的事件凭全局单调递增的 seq 重放，并由文档服务转发至素材服务与 Agent 服务。
10. **空对话安静（3.1）**：
    - 新开、尚未发过消息的云端对话为安静的空对话，不主动发起提示。
11. **改密退出确认超时与提示（3.2）**：
    - 退出确认超时缩短为 **45 秒**（推翻 10-13 的 120 秒）。
    - 超过 45 秒网页显示失败和 8 行折叠调试信息，有效权限不受影响，待服务确认到齐后改为办完。
    - 用户改密选“否”明确提示：「密码已修改。已登录的其它设备保持登录。」。
12. **搬到云端保留项目 ID 与连续历史序号（3.3）**：
    - **推翻 `087efab4` 重新生成项目 ID 的做法**，原项目搬到云端保留原项目 ID 与连续的历史序号。
    - 低版本客户端（<= 0.7.17）无法识别搬迁后的连续历史序号，阻断搬迁并提示「当前软件版本已过期，无法搬到云端」。
13. **云端项目另存为文件与重开规则（3.4）**：
    - 另存为文件（`.proc` / `.procp`）附带云端关联标记（原云端项目 ID、云端地址、保存时的权威历史序号等）。
    - 用户重新打开时遵循四条规则：未登录要求登录；非成员要求二级密码或申请加入；原项目已删转独立本地；连上原项目比对历史序号合并。
14. **后台作业等待与超时中断（4.1）**：
    - 后台作业排队时提示：「上一条消息发起的后台作业（转写、镜头识别等）还在做，做完就处理你这条消息。」。
    - 后台作业最多等 1 小时，超时中断提示：「后台作业等了一小时还没做完，已经中断；需要的话请重新发起。」。
    - 节点重启后回收任务槽位，中断任务标记失败。
15. **本机采集代下开放（4.2）**：
    - 本机素材采集代下正式开放，提示文案：「云端 Agent 正在用这台电脑上的登录下载：〈网址〉」；`web_handoff` live 联调可用。
16. **look 私钥归属（4.3）**：
    - look 的公私钥由主服务（master）持有，渲染节点与工作进程只拿票据或授权，不私藏主服务私钥。
17. **一键配特效要求（4.4）**：
