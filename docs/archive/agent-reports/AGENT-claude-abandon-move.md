### 修法

`server/docservice/shared-service.mjs`（第 300 行起，22 行）：文档服务订阅账本的项目变化（`authority.subscribeProjectChanges`，`hosted.mjs` 已经在用的同一个钩子），`op === 'delete'` 时照旧办法删项目的那几步做：还连着的会话以 4004 `deleted` 关掉（与旧办法同一个关闭码）、各模块丢掉这个空间的实例、去掉存储与模块缓存、删 `<dataDir>/tenants/<项目号>/`。账本里的登记与墓碑不动。

为什么文档服务能删：账本与文档数据在同一个文档服务进程里（`account-hosted.mjs` 建的账本，`initializeProject` 写的就是这个 `tenants/<项目号>/` 目录），不需要新的权限或通道。

**没修的**：素材服务那一份（第 6 行那条）。素材服务是另一个进程，素材按内容哈希存、沿用同一个号时不冲突，不挡这个按钮；但删项目同样留下孤儿素材库。记为**待用户项**：要不要在素材服务里也接上项目删除（它已经订阅访问事件，`project-access.mjs`），影响面是素材服务。

## 半成品的判据

`accountMove.ts` 的 `pendingAttempt`：

- 当前打开的是**能搬的东西**（没开协作的本地项目，或旧办法的本机协作房间；`moveSource()` 不为 null）。正在打开的是云端项目时为 null，不算。
- 这台设备的页面存储里有一条「**当前登录账号 + 当前本机项目号**」的搬迁记录（`MoveAttempt`），而且记录里**已经有云端回的项目号**。

为什么准：这条记录只由搬迁流程写（先记请求号再发新建，回了项目号再补上），搬成了在进项目之后就删掉。所以「记录在、带项目号」= 上次建好了云端项目、但没做完。不靠名字猜。

不算的：新建结果不确定（记录里没有项目号，云端建没建成不知道）；别的账号的记录；搬成了的。

删之前再问一次云端（`/hosted/shared/account/members`）：必须是当前账号建的；**没有别的成员、没有人的页面正连着**（托管方渲染节点、云端 Agent 的连接不算），否则不删（`in-use`）。理由：失败时也给过项目链接（关本机协作之后的失败、进项目失败），可能已经有人进来了，那就不是「半成品」了。

## 流程（`accountMove.ts` 的 `abandonMove`）

1. 认出半成品；没登录、不是能搬的东西、没有半成品，什么都不发。
2. 占「正在搬这个项目」的位（与搬迁共用，`pc.account.move.lock`）：另一个窗口正在搬就回「另一个窗口正在搬」。同一个窗口里搬与放弃互斥（`accountMoveFlow.ts` 的 `moving` / `abandoning`）。
3. 读成员（拿 `accessRevision`、判在不在用）；云端回 404 `no-project` / `project-gone` → 已经不在了，只清本机，算成功。
4. 删：`/hosted/shared/account/admin`，`op: "delete"`，带刚读到的 `accessRevision` 和新请求号（「删除项目」用的同一个接口；客户端原来没有这个方法，`client.ts` 加了 `deleteProject`）。
   - 回 404 → 已经不在，算成功；
   - 回 409 `access-revision-mismatch`（查完到删之间有人改了）→ 重新查一遍，这回有人加入了就不删，最多三轮；
   - 回包丢了、5xx → 再问一次云端，确认不在了算成功，否则失败（本机不动）。
5. 成功才清本机：搬迁记录按请求号删（只删这一条），本页内存里指向它的云端关联清掉。

### 本机关联记号

- 搬迁失败时本机项目文件里**本来就不记**这个云端项目：云端关联（`cloudAssociation`，另存文件时写进文件，重开四规则用的就是它）只在进云端项目成功的那一刻写（`enterAccountProject` 里在 `guard` 之后），失败的搬迁到不了那一步。
- 真正让「下次还去连它」的是页面存储里的搬迁记录：再点「确定」会接着往这个云端项目传。放弃时删的就是它。
- 防万一（进项目的半路出的错），本页内存里的云端关联若指向这个项目也清掉，另存文件时不会再写进去。

## 没做成的与原因

- **新建结果不确定的记录（没有项目号）不给放弃。** 云端建没建成不知道；要知道得原样重放那次新建，没建成的话这一下就把它建出来了。这种记录下次「确定」会原样重放，不会多建，留着无害。
- **按钮只认这台设备、当前登录账号的记录。** 在另一台设备上、或页面存储被清掉之后，半成品只能去网站「我创建的」里删（这就是 TODO 第 161 行的「成孤儿」那条，按任务书没做）。
- **账号项目设置里旧的「删除项目」按钮仍走旧办法的证明**，对账号项目不起作用（`AGENT-v18-move.md`「发现的现状问题」第 3 条）。没动，不在这次范围；有了 `client.deleteProject` 之后接上它很容易。
- **协作房间（搬到一半失败、本机协作还没关）**的「放弃」只有单测和界面代码，探针走的是本地项目那一种。
