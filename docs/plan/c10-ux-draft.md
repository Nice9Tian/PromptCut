- **编辑与撤销**：连不上文档服务时，用户可以「照常编辑，操作攒在本地；恢复后按顺序提交」，正常执行编辑与撤销。
- **导入素材**：连不上素材服务时不能执行素材导入，正在进行中的上传也会暂停。
- **导出**：允许发起导出。但根据「导出和像素级检查只用素材原尺寸；素材原尺寸还没到时提示等待上传方，不拿素材小尺寸代替导出」，若因为离线导致需要的素材原尺寸未能取到，导出进度会被拦下并提示等待上传方。

- **查看与 Agent**：由于文档服务同步受阻，无法看到别人期间的修改；在线浏览器模式下，AI 栏里的 Agent 无法使用（计划 cloud-task.md 目标 L 开头一段：「Agent 走 Agent 云端（agent 模式的进程在服务器，I）」）。
- **页面关闭**：因为「浏览器中关闭页面即结束本次编辑」，而且当前浏览器无法在关闭时注入自定义文案，因此依靠 1.7 的常驻提示栏进行警告。离线未提交操作在关页面时的具体去留见第 7 节第 1 点。
- **恢复与冲突处理**：恢复连接后系统按顺序提交。如遇冲突触发 1.6 对话框，由用户决定重放或丢弃。「被覆盖的一方在换成最新版本之前，先把自己那份存成本地备份」在此处是否适用见第 7 节第 14 点。而连不上素材服务时普通素材层显示什么兜底，见第 7 节第 10 点。

**与语义的对应**：

## 7. 需要主会话或用户定的点

1. **离线未提交操作在关页面时的去留**
   - **卡在哪**：语义没写。在线页面「浏览器中关闭页面即结束本次编辑」，而且当前浏览器无法在关闭时展示自定义提示。
   - **选项 A**：仅在页面内以「离线未提交状态栏」常驻警告，关闭页面时使用原生二次确认，一旦强行关闭，修改直接清空。代价：常驻横幅占据空间，强退痛失修改。
   - **选项 B**：关闭时同样仅有原生确认，但后台静默存入 IndexedDB。下次打开同一项目时按「离线」一节的规则提交（只有第一条带期望版本；被拒就整批停下，由用户选重放或丢弃）。代价：若用户清理了缓存或换台设备打开项目，很容易触发难以恢复的跨端大面积冲突。

2. **低内存档在浏览器中的素材导入权限**
   - **卡在哪**：纯浏览器没有转码能力，只能上传素材原尺寸。而「素材小尺寸由上传方在自己的机器上转码，素材服务不转码」。没有任何别的节点会替人生成素材小尺寸。低内存档平时又不拉原尺寸，这导致纯浏览器导入的素材在低内存档彻底失效。
   - **选项 A**：允许导入，但在预览画面显示等待状态。代价：上传完素材自己看不了，同项目里用低内存档的其他成员同样看不到。
   - **选项 B**：导入入口完全置灰，并提示低内存档无法上传素材。代价：极大限制了移动端用户的基本操作。

3. **浏览器放不了的素材原尺寸怎么预览**
   - **卡在哪**：语义写「素材原尺寸是浏览器放不了的编码时，预览一直用素材小尺寸」，但如前文，纯浏览器导入只有原尺寸且没人给转小尺寸。
   - **选项 A**：上传后预览直接显示「浏览器无法预览该素材」。代价：上传者自己看不了。
   - **选项 B**：前端拦截，禁止上传浏览器无法解码的格式。代价：浏览器变成了严格格式白名单。

4. **后台预渲染（L1）的让路规则**
   - **卡在哪**：计划 `cloud-task.md` L1 写「用户一操作……就让路，空闲再续」；但语义 `product/platforms.md` 写「本机 PC 和纯浏览器在用户播放、拖动时不认领新任务，手里在做的那一批做完为止」。有出入。
   - **选项 A**：按计划一操作立刻阻断当前渲染。代价：频繁中断导致产出效率极低。
   - **选项 B**：按语义把当前手里的那一批算完才让路。代价：用户的操作不受阻；代价是用户操作后设备还要继续算到这一批做完（耗电、发热），拖到的新位置所需的快照要多等这一批的时间。

5. **「不替别人的项目干活」的宣示可见度**
   - **卡在哪**：语义写「纯浏览器节点绝不替别的用户干活……也不让用户的设备算力被别人占用」，是否要在 UI 告知用户。
   - **选项 A**：在项目设置提供显式文案承诺。代价：增加了不必要的文本量，反而引人疑虑。
   - **选项 B**：仅做底层规则，界面不提示。代价：懂行的用户可能会疑惑后台占用。

6. **放本机项目页面在局域网内从哪提供**
   - **卡在哪**：语义写「服务器直接提供编辑器页面……页面连同一台服务器上的文档服务和素材服务」。
   - **选项 A**：由云端 `/editor` 伺服，页面再去连局域网。代价：HTTPS 连 HTTP 会被浏览器的混合内容策略强行拦截。
   - **选项 B**：由桌面版提供明文 HTTP 页面，局域网直连。代价：局域网里的明文 HTTP 页面不是安全上下文，浏览器只在 HTTPS 下开放的能力（例如导出视频编码、存文件选择框、剪贴板）会用不了。
   - **选项 C**：桌面版在局域网里用自己的证书提供 HTTPS 页面。代价：浏览器会报证书警告。

7. **浏览器如何承载不协作的新建项目文档服务**
   - **卡在哪**：语义写「本机没有进程，文档服务和素材服务都在别处」；但又说「草稿自动保存在本机」。纯浏览器建未协作项目时，文档服务没处放。
   - **选项 A**：浏览器只能加入不能新建本地草稿。代价：阉割了核心流程。
   - **选项 B**：新建时，文档服务和草稿数据全存在浏览器 IndexedDB。代价：架构异常复杂，清缓存即丢失。
   - **选项 C**：点新建直接在云端建立多用户协作项目。代价：消耗云资源，断网无法新建。

8. **在线浏览器模式里勾选多用户协作时的「放本机」分支**
   - **卡在哪**：语义写「勾上时的默认：放本机……」，但在纯浏览器中由于「本机没有进程」，它当不了放本机的主机。
   - **选项 A**：只能放云端，放本机单选框置灰并给出说明。代价：打破了勾上时默认放本机的承诺。
   - **选项 B**：直接隐藏放本机选项。代价：各平台项目设置界面不统一。
   - **选项 C**：照语义保留，选了再报错。代价：用户体验糟糕。

9. **在线浏览器模式能否在开始页打开本地项目包**
   - **卡在哪**：语义 `workflow/project.md` 没写纯浏览器开始页是否提供打开 `.proc` / `.procp` 的入口。
   - **选项 A**：提供入口并将解包内容载入 IndexedDB。代价：大包易致浏览器崩溃。
   - **选项 B**：隐藏该功能。代价：浏览器接续协作能力受限。

10. **连不上素材服务时普通素材层显示什么兜底**
    - **卡在哪**：语义写「预览里任何一层都不无提示地透明」。若连不上素材服务导致连普通的图片/视频素材都没取到，显示什么？
    - **选项 A**：和重卡缺渲染结果一样，统一显示「沙漏 + 噪点」占位符。代价：无法区分是需要后台算力还是素材没下载到。
    - **选项 B**：显示专用的灰色底块加素材缺失图标。代价：增加额外前端实现成本。

11. **无法渲染的用户卡在时间轴上的提示与交互**
    - **11.1 时间轴提示位置**：
      - 选项 A：提示浮在对应片段上方。代价：时间轴缩小时文字挤成一团。
      - 选项 B：在时间轴上方通栏警告。代价：无法直观看出是哪个片段。
    - **11.2 时间轴片段交互**：
      - 选项 A：片段可选中、移动、改时长、改参数；「电脑 + 离线」图标可点击查看说明。代价：参数改完无法看效果，等于盲改。
      - 选项 B：片段完全置灰锁定只读，图标不可点。代价：阻断了用户纯调时间的排版意图。

12. **在线浏览器能否利用别人渲染的用户卡快照**
    - **卡在哪**：兜底顺序写对「用户卡」「常驻显示」，但不走兜底顺序；但语义又写「可以从素材服务取别人预渲染好的快照，直接用在可见舞台上」。两者存在张力。
    - **选项 A**：遵照「常驻显示」，有快照也不显示。代价：浏览器失去了协作预览的意义。
    - **选项 B**：如果有别人的快照就贴图，没有才「常驻」。代价：略微修改对「常驻」的字面解释。

13. **后台预渲染在页面切到后台时的状态**
    - **卡在哪**：计划 cloud-task.md L1 写不可见时「按 E4 每 8 帧让出」，后台仍会跑，是否在 UI 上告知？
    - **选项 A**：在标签页上加渲染中字样。代价：干扰原有网页标题。
    - **选项 B**：无特殊提示。代价：缺少状态可见性。

14. **离线发生版本冲突时备份策略的适用性**
    - **卡在哪**：冲突规定「被覆盖的一方在换成最新版本之前，先把自己那份存成本地备份」。若用户在离线重放对话框选「丢弃」，此时还适用吗？
    - **选项 A**：适用，弹窗提示丢弃前会存一份本地备份。代价：恢复和管理界面开发成本极高。
    - **选项 B**：不适用，选「丢弃」即彻底丢弃。代价：丢失用户离线修改。

15. **浏览器是否应记住曾进入过的共享项目**
    - **卡在哪**：语义没写纯浏览器开始页是否应记忆云端协作项目（特别是点击新建即在云端创建并重定向时）。
    - **选项 A**：记住并提供最近访问列表。代价：需在浏览器本地存储列表记录。
    - **选项 B**：不记住，每次关页后都必须重走「加入别人的项目」。代价：用户反复进出会觉得极其繁琐。

## 8. 名词对照

- **文档服务**：接收信息、记录版本、转发分发消息的调度中转站。无渲染和存储计算能力。出自 `product/document-service.md`「职责」及 `glossary.md`。
- **素材服务**：按哈希存取素材、视频或预渲染结果的唯一存储与分发入口。出自 `product/asset-service.md`「职责」及 `glossary.md`。
- **在线浏览器模式**：不依赖本机预渲染进程、纯用页面环境进行操作渲染的运行形态。出自 `product/platforms.md`「在线浏览器模式」及 `glossary.md`。
- **渲染节点**：从任务队列认领并完成预渲染任务的地方。文档服务不主动把任务派给谁。出自 `product/platforms.md`「渲染节点」及 `glossary.md`。
- **后台舞台**：在闲时负责实测预算、并兼职产出快照推送给素材服务（作为浏览器渲染节点角色）的不可见页面进程。出自 `glossary.md`。
- **素材原尺寸 / 素材小尺寸**：导入时原始文件与通过压制缩略而来的预览副本。出自 `product/asset-service.md`「两档素材」及 `glossary.md`。
- **预渲染原尺寸 / 预渲染小尺寸**：渲染节点导出的正式产物及用来快速预览的同比例缩小副本。出自 `product/rendering.md`「重管线：预渲染」及 `glossary.md`。
- **低内存档**：为的是省电与流畅，只看预渲染小尺寸和素材小尺寸，平时不拉原尺寸的运行档位。出自 `product/platforms.md`「面向的平台」及 `glossary.md`。
- **用户卡、图卡**：卡片在语义术语表中仅分为 DOM 卡、图卡、组合卡、素材封装卡四种形态；「用户卡」仅在 `product/platforms.md` 等中提及，术语表未对其做单列定义。
- **本机 PC**：具备独立渲染能力和转码功能的本地桌面软件预渲染进程载体。出自 `product/platforms.md`「渲染节点」及 `glossary.md`。
- **本地草稿、本机**：未设置多用户协作时的项目存放状态。出自 `workflow/project.md`「开始」。
- **主机地址**：成员连接本地项目的地址。出自 `glossary.md`「系统角色」表「云端托管服务」一行（「通过才给主机地址」），以及计划 `docs/plan/Master-Execution-Plan.md` C10 其余的「手填主机地址」。
