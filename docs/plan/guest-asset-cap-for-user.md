# 游客能占多少盘：一个还没定的上限（A3）

给用户过目用。**这里不替你定数**，只把口子、现状、不设上限的后果和几种做法摆出来，最后说我建议哪一种、为什么。

## 一、口子是什么

你 2026-10-23 定的游客限额原话是：「每一条源文件不能大于100M。总视频素材不能大于三条。」

这两句都落地了，而且是硬的。但它们合起来**管住了条数，没管住总量**：被数的只有视频，**图片和音频不计条数**。所以一个游客可以传任意多张 100 MB 的图、任意多条 100 MB 的音频，谁也拦不住。这就是 A3。

## 二、现在实际是什么样（我逐条看过代码，不是听转述）

| 这一条 | 现在 |
|---|---|
| 每个文件多大 | 最多 100 MB，**所有类型都查**（视频、图片、音频，连视频的小档预览也查） |
| 视频几条 | 最多 3 条。**按文件头字节认**，不是按文件名——把 mp4 改名叫 `.jpg` 照样被认出来；把每一片都标成「小档」也没用，服务端按「原件数和小档数取大的那个」算 |
| 图片、音频几条 | **不限**。这就是口子 |
| 存多久 | 3 天，到点整个项目被删，**素材字节真的从盘上回收**（这一条今天刚补上，之前只是把项目标成已删除、字节还留着） |
| 一个游客能建几个项目 | 1 个 |
| 一个 IP 能领几个游客身份 | 每小时 20 个 |
| 游客能不能用云端 Agent | 不能，被一道闸挡着（所以不会产生模型费用） |

一句话：**条数这一侧已经拧紧了，总量这一侧完全敞着。**

## 三、不设上限，最坏会怎样

不是「有人恶意刷」才会出事，正常使用也可能撞上——但最坏情况要按有人故意算：

- 一个普通家庭宽带（上行 100 Mbps，约每秒 12.5 MB）全速传，一天能推上去约 **1 TB**。
- 东西要 3 天才清，所以同一条宽带持续推，盘上**常驻约 3 TB**。
- 每小时 20 个身份这道闸拦不住这件事：一个身份、一个项目，就够装下无限张图。
- 节点现在系统盘 39 GB、数据盘 40 GB。**几十分钟就能把盘塞满**，塞满之后真实用户（付费的、协作的）也写不进去。

所以这不是「以后再说」的事，是**一台机器被一条宽带打满**的量级。

## 四、几种做法，各自的代价

### 甲：每个游客一个总字节上限（所有类型一起算）

比如「一个游客总共不超过 N MB」。超了就拒新的上传。

- **好处**：服务端自己能算，游客骗不了（不看文件名、不看页面说什么，只看实际字节）。一条规则同时管住图片、音频、视频，连「视频 3 条」都可以留着当第二道闸，也可以直接退休。
- **代价**：要给用户一句说得清的提示（「你这个游客身份还能传 XX MB」），界面上多一个进度条之类的东西。工作量不大。
- **数怎么选**（**由你定**，下面只是参考后果）：

  | 总上限 | 一个游客能装下什么 | 1000 个在线游客占多少盘 |
  |---|---|---|
  | 300 MB | 3 条小视频，或几十张图 | 约 300 GB |
  | 1 GB | 3 条一般长度的视频 + 一些图 | 约 1 TB |
  | 3 GB | 3 条高码率长视频 | 约 3 TB |

  （现在的节点数据盘是 40 GB，所以这三档都要配合下面的「乙」才扛得住极端情况。）

### 乙：整台节点给游客划一个总盘

比如「所有游客加起来不超过 X GB，满了就暂时不收新游客」。

- **好处**：**这是唯一能保证真实用户写得进去的做法**。甲只能限制单个游客，拦不住「很多个游客一起来」。
- **代价**：满了之后新游客会被挡在门外，看到的是「现在人太多，请稍后再试或注册账号」。对真想试用的人是一次不好的体验。

### 丙：把条数上限扩大到图片和音频

比如「图片 20 张、音频 10 条」。

- **好处**：改动最小，和现在的做法同一套。
- **代价**：**仍然不封顶**——20 张 × 100 MB 还是 2 GB。只是把口子从「无限」缩到「很大」，没有真正解决。

### 丁：维持现状，靠 IP 限流和 3 天清理兜着

- **好处**：不用做。
- **代价**：上面第三节那个 3 TB 就是代价。我不建议。

## 五、我建议

**甲 + 乙一起上，丙不要做。**

- **甲**（每个游客一个总字节上限）是正事：它把问题从根上解决，而且不可伪造。
- **乙**（节点总盘）是保险：甲管得住一个人，管不住一千个人同时来；没有乙，真实用户还是会被挤掉。
- **丙**看着像在做事，其实只是把无限改成很大，不值得花这个工夫。

至于**数定多少，我不替你定**。要我给个起步建议的话：先把乙定在「数据盘的一半」这种保守值，甲从上表里挑一档试一个月，看实际用量再调——甲的数改起来只是一行配置。

## 六、顺带一提，这件事不包括什么

- **云端 Agent 的费用**（原来记作 S8）已经不用在这里考虑了：游客现在根本用不了云端 Agent，你今天也定了「先不做，等护栏好了再做」。
- **每条源文件 100 MB** 这一条不用动，它已经在管每个文件了；这里讨论的是「一共能传多少」。
