## 已经做了什么

本次收回的基础模块包括：

- 账号内部协议与持久账本：核对账号凭据、记录项目权限事件，为后续服务接入提供基础。
- 对话与任务权限：共有/私有控制、按到达顺序排队、读消息确认、被踢或退出后的任务保留/撤销，由统一权限模块判断。
- Agent 实例认证：每次调用绑定当前实例与注册代际，验签并防重放；旧实例不能借相同证书恢复权限。
- 素材票据：绑定项目、任务和素材版本，核对完整 HTTP 请求与实际 TLS 连接。项目物理素材服务和生产登记仍在接线，尚未交付整个素材功能。
- 工具基础：可信任务上下文、资源关闭登记、持久作业账本、按项目和对话隔离的工作目录与额度检查。

这些是已测试的独立模块，**尚不代表云端 Agent、账号项目界面或整个 0.7.18 已验收**。
源码从共同验证提交 `cbe8398d` 逐字收回；未把 B 素材传输和 G 中央接线的在途修改放入本阶段。

另外已经完成：

- 三版本迁移设计、接口和用户新决定的文档对齐，详见[迁移设计](three-versions-018-design.md)。

- 用户授权的节点 Python 升级：三个元包升级并安装 venv，实际解释器仍为 3.10.12，原服务未重启。本机 cuda_Vit 未改。
