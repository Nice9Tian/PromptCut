## 已经做了什么

本次收回的基础模块包括：

- 账号内部协议与持久账本：核对账号凭据、记录项目权限事件，为后续服务接入提供基础。
- 对话与任务权限：共有/私有控制、按到达顺序排队、读消息确认、被踢或退出后的任务保留/撤销，由统一权限模块判断。
- Agent 实例认证：每次调用绑定当前实例与注册代际，验签并防重放；旧实例不能借相同证书恢复权限。
- 素材票据：绑定项目、任务和素材版本，核对完整 HTTP 请求与实际 TLS 连接。项目物理素材服务和生产登记仍在接线，尚未交付整个素材功能。
- 工具基础：可信任务上下文、资源关闭登记、持久作业账本、按项目和对话隔离的工作目录与额度检查。

这些是已测试的独立模块，**尚不代表云端 Agent、账号项目界面或整个 0.7.18 已验收**。
源码从共同验证提交 `cbe8398d` 逐字收回，独立 main 候选 `f41c5ff9` 类型、全量和网页构建已通过；未把 B 素材传输和 G 中央接线的在途修改放入本阶段。

另外已经完成：

- 三版本迁移设计、接口和用户新决定的文档对齐，详见[迁移设计](three-versions-018-design.md)。
- 节点 ffmpeg、中文字体、Chrome、采集工具安装与独立工具烟测。
- 用户授权的节点 Python 升级：三个元包升级并安装 venv，实际解释器仍为 3.10.12，原服务未重启。本机 cuda_Vit 未改。

## 待用户项

已经拍板的共有/私有控制、多人排队、退出设备范围、关闭 spawn_agent、素材采集和禁止跨项目读素材，不再列为待决定。

渲染补充明确保留的三组决定：

- 当前项目空闲未满五分钟时，是否可以提前让位给等待项目。
- 补渲失败或持续无进展后，是终止，还是保留待办供重试/取消。
- 对话删除的权限、确认、共有归属和计数、释放名额时机及在途任务处理。50 个满额阻新建、不自动删历史和补删除入口已经确定。

技术机制的选择和旧裁定明细见[迁移设计](three-versions-018-design.md)与[裁定清单](three-versions-rulings.md)，不冒称用户逐字段批准。模型密文导入已有授权，不是待用户项。
