## 目标

桌面壳从 Tauri（Rust）换成 Electron，出 Windows 与 macOS 两个平台。只换「壳」这一层；预渲染与导出的 chrome-headless-shell 加 beginFrame 那条路保留。

做完用户得到：Mac 版；两个平台上编辑界面与成片是同一个 Chromium 内核。

## 与前两期的约定

- **主进程起二期做出的「静态页面 + 独立 Node 服务」。** 二期没做完就开本期的话，先起现有的那一套（Vite），二期完成后只换启动命令。
- **第 0 步不依赖一期、二期**，不改仓库现有文件，可以在任何空档先做。
- **paint 只能是第二个取帧后端。** 探针、验证脚本、一期的云节点渲染服务、Linux 上的 Agent 端都在没有 Electron 的纯 Node 里跑，仍靠 chrome-headless-shell。
- **像素基线按平台各一份**；桌面若改用 paint 后端，再按后端各一份。都要事先经用户确认，并与二期 M5 的缓存换键错开告知用户。

## 要换掉的外壳现状（2026-10-05）

`desktop/src-tauri/src/` 共 9 个文件、约 2400 行，外壳版本 0.2.7，平台专用标注 7 处。`electron-mac-plan.md` 里写的「`lib.rs` 695 行、6 处」是 10 月 1 日的数，以这里为准。要在 Electron 里做出等价物的有：

| 模块 | 管什么 |
|---|---|
| `lib.rs` | 主窗口、起后台的 Node 进程（现在起的是 `node_modules/vite/bin/vite.js`）、命令注册 |
| `background.rs` | 后台运行：关掉编辑界面不退出，转托盘图标继续跑；收起是把主窗挪到屏幕外，不是隐藏 |
| `skill_shell.rs` | 悬浮窗，以及 SKILL 模式在外壳这一侧的显示 |
| `agent_webview.rs` | Agent 上网用的子窗口，带调试端口，Node 侧经调试协议连它 |
| `proc_lock.rs` | `.proc` 文件的独占锁，由外壳持有 |
| `kill_on_close.rs` | 把后台进程拴在外壳上，外壳怎么死都一起收走 |
| `chrome_color.rs`、`chrome_path.rs` | 采样原生菜单栏的颜色；Chrome 路径的规范化 |
