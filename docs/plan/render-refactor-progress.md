## 没做到的与原因

任务书各项里目前没有记「未达成」的。甲三留下三处没做到底的：账号项目里「渲染节点」和「生成轨道流」现在只是能改、能看，托管方的渲染服务还看不到账号项目，要等 0.7.18 把它接进账号项目；清单计划里被并成组流的卡，渲染服务不为它们产流；云端 Agent 服务发的清单计划不带这一项，打开后对它是「下一次改动起生效」。甲二留下四处没做到底的：同步来的用户卡和素材效果卡不走本页产流（它们现在在哪里都没有单卡流，页面一侧也算不出和桌面相同的键）；「先查到另一种环境产的流」只有单测，没有端到端验（同一台机器上两个浏览器的环境指纹相同）；独立渲染主机没接「先查」，可能把页面产过的流再产一遍，画面不会错；稀疏那一趟只留了口子。修「套了一层认不出卡」留下一处小尾巴：挂了强调、滤镜的画布卡，在排队的轻重和快照体积上限这几处仍按普通卡算（根子在一个这次不许动的公共文件里；快照作废以后体积上限这一条自然没有了）。下层一留下一处：在线页面发的清单计划不出这种流（要改清单计划的切分，归后面的下层四一起做）；它另外发现素材段的像素映射变了、那一层的缓存内容键不变，别处有没有因此该失效而没失效的没查。另外托管方渲染节点在语义里还没有成段的描述（`product/hosting.md`、`mechanism/hosting.md`），等用户确认文档后和别的语义一起补。
