## 目标

用户新买了一台 Ubuntu 云节点，要它承担文档服务、素材服务、渲染服务、Agent 服务。手机用户和轻量浏览器用户右侧用不了 Agent 时，在线页面把请求转给云节点，由云节点上的 Agent 以这个用户的身份工作。

做完用户得到：手机和轻量浏览器用户的重卡有节点渲；右侧 AI 栏经云端 Agent 能用。

## 与后两期的约定（本期必须守）

- **Agent 独立入口对前端代码的依赖只经一处载入缝**（现在是 `server/agent/ssr-host.mjs`），不新增别的直接引用。二期要把它搬进新目录，守了这条二期只搬目录、不返工。
- **云节点上照旧跑 Vite。** Agent 服务端要载入页面那套工具实现、store、卡片与部件注册表（卡片是 TSX），现在只有 Vite 能载；独立渲染主机也是这么起的。「脱离 Vite」是二期的事，本期不做。
- **不动桌面壳。** 桌面版改用同一个 Agent 入口时，用户看到的行为不变。

## 步骤

### 1. 新节点装文档、素材、在线页面

不依赖别的工作，现在就能做。

- 现状：现成。`server/hosted/main.mjs` 一个进程两个端口，阿里云上长期在跑。
- 做法：`scripts/remote/docservice.mjs` 的 `install`（装 Node 与 PM2）、`deploy-hosted --write-token --save`（用法在脚本文件头）。
- nginx 配置不在仓库里：从旧机器抄 `/etc/nginx/sites-enabled/promptcut`、`promptcut-stages`，改域名与 `proxy_bind` 的内网地址；两个舞台子域要 DNS 与证书；要开 `gzip_types` 与 `gzip_static`（`hosting-migration.md` 第 1 步）。
- 完成的标志：`/healthz` 通；在线页面能加入一个测试项目并读到素材；真机路径探针对新地址通过。

### 2. 渲染服务常驻

- 现状：`scripts/render-host.mjs`（独立渲染主机）有代码，只在测试容器里以探针方式跑过，没在云服务器上常驻过。它跑的是完整仓库加依赖，不是托管端那份精简清单。
- 要补：常驻配置与部署脚本；root 下 Chrome 自动加 `--no-sandbox`（`cloud-task.md` I0 写了、代码没做，现在只能靠环境变量 `PC_CHROME_ARGS` 手工传）；中文字体与启动自检；ffmpeg 在 PATH。
- 机制缺口：它要每个项目一份项目凭证写进配置才能取活（`render-host-contract.md`）。要自动为节点上所有项目服务，得新定「托管方自己的渲染身份」。
- 完成的标志：手机低内存档打开一个含重卡的项目，补渲任务被云节点认领、产物贴上；节点重启后自动恢复取活。

### 3. Agent 服务独立入口与云端 Agent（本期主体）

缺口（2026-10-05 查代码）：

1. **没有独立进程与对外接口**：`/api/ai/chat`、`/api/mcp/*`、`/api/agent/*` 都是编辑器进程的同源中间件（`server/vite-plugin-ai.ts`）。
2. **单项目、单用户**：绑定的项目只有一份（`agentBinding`），后绑的顶掉先绑的；审查环路锁、额度熔断、登录状态、`ai.json`、对话记录都是进程级全局。
3. **在线页面一侧是剪掉的**：右侧是占位（`src/editor/dock/DockPages.tsx`），工具通道在在线构建里整个删了；「在线页面不请求 `/api/*`」有守卫和只减不增的棘轮清单（`c10a-contract.md`）。
4. **身份与票据依赖页面**：文档服务已认 `agent` 角色（`auth-contract.md`），但连接票据靠同机页面签，有效期 2 分钟；托管部署下素材票据没接。
5. **Agent 的「看」**：云端要一个只做即时渲染的进程和按需拉素材的本地库（`cloud-task.md` I2、I3 未做）。
6. **读页面状态的工具**（选区、播放头、播放暂停）要经公网问用户的浏览器，或在云端降级。
7. **模型凭证与计量**：服务器上走不了命令行订阅的浏览器登录，现实做法是 API 直连（`server/harness/`）；按用户的上限、并发、计费没有任何设计。

分三步做：

| 步 | 做什么 | 完成的标志 |
|---|---|---|
| 3a 独立入口 | Agent 服务不带编辑页也能起，带鉴权，按「用户 × 项目 × 对话」分实例；进程级全局状态改成按实例。桌面版改用同一个入口 | 桌面版 Agent 相关测试与探针不变红；同一进程里两个项目各一个对话互不干扰 |
| 3b 在线页面接上 | 右侧占位换成可用的 AI 栏，对话与工具经云节点转发；连接票据与素材票据接上。先只支持 API 直连，只开改项目的工具 | 手机上发一句话，项目被改，别的成员看到改动且署名正确 |
| 3c 补齐 | 云端的「看」（即时渲染进程、按需拉素材）；读页面状态的工具；每人上限、并发上限与计量 | Agent 在云端能看一帧画面；超过上限的请求被明确拒绝并告诉用户原因 |
