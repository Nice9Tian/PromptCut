# PromptCut 共享项目交互与文案设计 (C6.5)

> 〔2026-09-26 第二轮〕本稿是 C6.5 两个旧入口的交互稿。稿中的界面文字（「新建共享项目」「打开共享项目」「互联网模式」「局域网模式」）照当时界面原样保留，作记录；它们现在分别叫「多用户协作」、开始页的加入、「放云端」「放本机」（`docs/semantics/workflow/project.md`）。新的交互稿随 C10a 另出。

## 1. 「新建共享项目」对话框

**组标题：基本信息**
- **项目名** 
  - 标签：项目名
  - 占位文字：给项目起个名字
  - 校验提示（空）：项目名不能为空。
  - 校验提示（超长）：建议不要超过 30 个字。
  - 校验提示（重名）：这个项目名已被占用，换一个吧。
> 理由：字段分界线使表单结构清晰。超长上限设为 30 字，避免在 TopBar 显示时挤占太多空间；重名校验防覆盖。

- **创建者用户名**
  - 标签：创建者用户名
  - 占位文字：你的名字
  - 校验提示（空）：创建者用户名不能为空。
  - 校验提示（超长）：建议不要超过 20 个字。
> 理由：确保参与者有合理标识。

- **创建者密码**
  - 标签：创建者密码
  - 占位文字：设置一个密码
  - 校验提示（空）：密码不能为空（用于删项目、踢人等特权）。
  - 校验提示（太短）：建议至少 4 个字符。
> 理由：密码作为特权护城河必须填写，给合理的长度建议防止弱密码。

**组标题：部署位置（选定后不能改）**
- 选项 A：**互联网模式**
  - 说明：托管在阿里云。只要有网，成员随时能打开项目。
> 理由：转化为用户能懂的云端概念。
- 选项 B：**局域网模式**
  - 说明：本机当主机。成员要在同一个 Wi-Fi 或网段下才能连上。
  - 纯浏览器环境表现：置灰不可选。附加说明：纯浏览器不能当主机，要在桌面版客户端使用局域网模式。
  - 选中时警告：[警示色图标 + 文字] 本机关机或退出软件后，其他成员打不开这个项目。
> 理由：按 12.2，局域网必须本机当主机，纯浏览器无此能力所以禁用。关机断联是物理限制，必须在创建时明确声明。

**组标题：进入方式（选定后不能改）**
- 选项 A：**自由进入**
  - 说明：设置一个项目密码，知道名字和密码就能进。
  - 附加字段：**项目密码**
  - 占位文字：团队共用的密码
  - 校验提示（空/太短）：不能为空，建议至少 4 个字符。
> 理由：按语义自由进入统一共用项目密码。
- 选项 B：**限定进入**
  - 说明：提前写好名单，只有名单里的人用各自的密码才能进。
  - 附加交互：显示名单表。创建者自动为第一行，带有 `[创建者]` 标签，固定不可删、不可改，密码列显示「同创建者密码」。
  - 下方新增行：左侧「用户名」，右侧「密码」，后跟「添加」按钮。
  - 校验提示（新增行空）：用户名不能为空。 / 密码不能为空。
  - 校验提示（重名）：名单里已有这个名字，换一个区分一下。
  - 条目删除：鼠标悬停在非创建者行，右侧出现删除图标。
  - 提示文字：如果有独立渲染主机，记得在这里给它也加一条名单。
> 理由：创建者作为发起人必然在名单内，12.2 节规定了不可删，锁定信息解决了密码多头管理的问题。独立主机提醒是因为它需要独立的凭证。

**底部操作与提示文案**
- 按钮：取消 / 创建
- 状态提示：
  - 创建中：正在创建...
  - 创建成功（互联网）：创建成功，已进入项目。
  - 创建成功（局域网）：创建成功。让成员在同一个网段下查项目名就能进。记住本机要保持开着。
  - 端口占用：本机端口被占用，先关掉占用的另一个 PromptCut 窗口，或重启软件试试。
  - 网络错误：连不上阿里云，检查一下网络。
  - 字段不合法：检查红色的错误提示，填全并改对后再创建。
> 理由：局域网创建成功后给出明确的成员操作指示；端口占用给出具体解决建议（关掉另一个窗口）而不是仅说重启软件。

## 2. 「打开共享项目」对话框

**第一步：查找**
- 字段：**项目名** 
  - 占位文字：输入想找的项目名
- 入口：右上角灰色文字按钮 **托管地址**。
  - 点击展开：显示输入框，缺省值为内置阿里云地址。
  - 旁附按钮：恢复默认。
- 按钮：取消 / 查找
- 状态文案：正在局域网和阿里云查找...
- 查找网络策略与文案：
  - 如果只有一边连不上，但不影响另一边找到了项目：静默进入第二步，不弹强打断报错（可在角落出气泡：阿里云连不上 / 局域网查找失败）。
  - 如果两边都连不上：局域网和阿里云都连不上，检查一下网络。
  - 找完且没发现：找不到这个项目，检查名字对不对，或者局域网主机开没开机。
> 理由：隐藏托管地址符合「不打扰普通用户」原则；查找时不因为一端网络故障而阻断另一端的可达项目，保证高可用感。

**插入步：并列选择（仅发现重名时出现）**
- 标题：找到两个同名项目，你要进哪一个？
- 选项 A：`[互联网模式] 托管在阿里云`
- 选项 B：`[局域网模式] 主机：{设备的显示名}`
- 按钮：返回
> 理由：局域网显示主机设备名，方便用户在办公室等同网段环境中区分是哪台电脑。

**第二步：验证（根据项目模式展示）**
- **自由进入**：
  - 字段：**项目密码**（占位：输入项目密码）、**你的用户名**（占位：报上你的名字）。
  - 次要入口按钮：**我是创建者**。点击后切换为：**创建者密码**（占位：输入创建者密码），用户名框置灰预填创建者名字。
> 理由：落实 12.2 节语义——自由进入下创建者可通过自己凭证直接进入。

- **限定进入**：
  - 字段：**用户名**（占位：输入名单里的用户名）、**密码**（占位：对应的密码）。
  - 次要入口按钮：**我是创建者**。点击后预填用户名框并置灰，只需填创建者密码。
> 理由：限定进入下创建者一定在名单中且为首条，提供快捷入口免去手打名字。

- 按钮与状态：
  - 按钮：返回（回到查找步） / 取消 / 进入
  - 进入锁定状态：密码连错时，按钮置灰，文案变为 `进入 (59s)`。
- 错误提示文案：
  - 密码错或名单外：用户名或密码不对。忘了的话找创建者问一下。
  - 尝试过多：尝试太多次，等 60 秒后再试。
  - 已被踢（登录拦截）：你被创建者踢出了这个项目。想回来，找创建者撤销。
  - 离线（局域网）：连不上主机，可能对方已关机或退出了软件。
  - 离线（阿里云）：连不上阿里云，检查一下网络。
> 理由：防撞库套取名单，所以密码错和不在名单内统一口径，不透露细节；由于没有密码找回功能，明确指导用户去找创建者问。被踢后登录给出明确退路指引。

## 3. 成员列表

- **位置与入口**：顶栏右侧，双人头像按钮。
- **角标文案**：例如 `成员: 3 人`。
- **列表为空**：下拉浮层展示 `只有你自己在线。`
> 理由：空列表给一个明确的状态兜底，防止浮层里全白。

- **行视觉与文案**：
  - 按设备分行显示。
  - 重名设备名后缀：`张三 (MacBook)`
  - 本人行：字体加粗，后缀 `(自己)`。
  - 创建者标识：名字旁加上带底色的 `[创建者]` 标签。
  - **Agent 标签视觉**：`[Agent ×2]` 显示为灰底实心圆角小标签。
  - **展开 Agent**：点击行展开子树，格式严格为 `张三 · Agent · 第 1 个对话`。
> 理由：落实 12.2 节的创建者身份可视性，Agent 的展开文案严格对齐用户指令要求的规范。

- **行内交互（踢人入口）**：
  - 当我是创建者时，鼠标悬停（Hover）在非本人的其他成员行上，右侧出现红色的「踢出」按钮。
> 理由：操作直观，将高频管理操作融入上下文，但不显示在自己那行，防止误伤自己。

## 4. 创建者操作入口

- **身份验证通用弹窗**：
  - 点击任何特权操作前，先弹窗拦截。
  - 标题：验证创建者身份
  - 字段：**创建者密码**（占位：输入创建者密码）
  - 报错：密码错误。 / 尝试太多次，等 60 秒后再试。（输入框锁定）
  - 按钮：取消 / 验证
> 理由：落实「每次都要当场输入创建者密码」的硬安全原则。

- **(a) 改项目密码（限自由进入）**：
  - 字段：**新密码**、**确认新密码**
  - 校验：两次输入不一致。
  - 提示：在线的人不受影响，下次进入要用新密码。
  - 按钮：取消 / 确认修改
> 理由：原密码在特权验证已过，此处直接改新。明确通知影响范围。

- **(b) 改名单（限定进入）**：
  - 交互：展示现有名单列表。创建者行固定不可删、不可改，密码列显示「同创建者密码」。
  - 增改删：列表底部有新增框。Hover 已有行出现「修改密码」图标（点击变输入框）和「删除」图标。
  - 提示：独立渲染主机是在另一台机器上帮你跑后台预渲染的 PromptCut 实例。如果有，在这里给它加一条专属名单，并在那边凭该用户名密码登录。
> 理由：列表管理完整覆盖增删改。对独立渲染主机的解释需要足够大白话，确保高阶功能可被普通用户理解和运用。

- **(c) 踢人与撤销禁入**：
  - 踢人二次确认：确定要把 用户名 (设备名) 踢出项目吗？
  - 踢人成功提示（自由模式）：已踢出。自由进入模式下，想彻底挡住，要改项目密码。
  - **撤销禁入入口**：成员列表底部，创建者专用区域除了上面操作，增加一项「已禁入的设备」。
  - 撤销交互：点击弹窗列出曾被踢的设备列表。行右侧有「撤销」按钮。
> 理由：落实 12.2 节中的禁入可撤销逻辑，以及自由模式下踢人容易引发的密码漏洞警告。

- **(d) 删项目**：
  - 二次确认（互联网）：确定要删除这个项目吗？托管在阿里云的项目文档和素材将被永久销毁，所有成员立刻断开。此操作无法恢复。
  - 二次确认（局域网）：确定要删除这个项目吗？本机作为主机的项目数据将被永久销毁，所有成员立刻断开。此操作无法恢复。
  - 交互：下方提供输入框，占位提示 `输入项目名确认`。
  - 按钮：取消 / 永久删除项目（只有输入完全匹配时，按钮才从置灰变为可点）。
> 理由：不同模式数据销毁位置不同，需严格分案。最高危操作用手打项目名做物理拦截，防止误点。

## 5. 被操作方看到的提示

- 阻断级弹窗（居中模态，只有「开始页」按钮，强行断开编辑）：
  - **被踢出（在线时）**：你已被创建者踢出该项目，无法继续编辑。想回来，找创建者撤销。
  - **被移出名单（在线时）**：你已被移出名单，连接已断开，无法继续编辑。
  - **项目被删除（在线时）**：项目已被创建者删除。回开始页新建或打开别的项目。
> 理由：对于剥夺权限和数据销毁，在线成员必须立刻强制断开并回开始页。明确指示出下一步可做的动作，避免用户卡死。

- 非阻断级提示（右上角 Toast 气泡，不打断编辑）：
  - **项目密码被改（在线时）**：项目密码已被修改。你当前的连接不受影响，但下次进入需要新密码。
> 理由：密码修改本质是拦截新连接，按语义无需干扰在线已经连进来的成员干活。

## 7. 语义疑点

在根据最新约束调整交互与文案时，发现以下几处边界在语义文档中可能未被完全锁死，现列出供主会话和架构确认：

1. **被移出名单时，在线的人是否立刻断开？**
   - 语义中未明确写清限定进入模式下，修改名单移除某人时，正在该项目内编辑的该人连接是何表现。
   - **本次设计的假定**：处于安全考虑，本次交互假定**会立刻断开其连接**，并弹窗提示「已被移出名单，连接已断开，无法继续编辑」，按钮强制导向开始页。
2. **纯浏览器设备的「设备名」方案**
   - 按 `12.2` 节所提，纯浏览器拿不到真实的物理设备名。此处在名单重名展示、被踢提示中会涉及设备名，需要代码侧提供近似方案（如 User-Agent 嗅探出的 OS+Browser 作为伪设备名）。该处理方案的接受度需确认。
3. **纯浏览器端无法作为局域网主机的 UI 呈现**
   - 物理上纯网页是不可能的。本设计在「新建共享项目」时采用了「展示该选项但置灰禁用，并附带解释」的方案，以防用户在网页端找不到功能而产生疑惑。
4. **自由进入下创建者的进入方式**
   - `workflow/project.md` 中自由模式只写了「填项目密码和自报的用户名」，但根据 D9 衍生的 `12.2` 节规定，创建者凭其密码进入时免于常规限制。本设计在打开项目的自由模式下专门补入了一个「我是创建者」的辅助入口，以满足 12.2 节的特权通道要求。
