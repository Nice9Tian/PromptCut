## 各期怎么衔接

各期约定见对应文件；新增的 0.5 期约定集中写在 `draft_sound-effects.md`，原三期文件保留不动：

- 顺序为 **0.5 期声音 → 一期云节点与 Agent 分离 → 二期前后端分离；原三期 Electron 已取消**。声音先在当前架构完成，不等新节点或独立 Agent；以后复用同一份 JS 合成器与素材产物接口。
- 一期的 Agent 独立入口，对前端代码的依赖只经一处载入缝；二期把它搬进新目录，不返工。
- 一期的云节点上照旧跑 Vite；脱离 Vite 留给二期。
- 二期的「桌面壳脱离 Vite」只动 Node 层，保留 Tauri 外壳；由现有外壳启动二期做出的服务。
- 二期最后一步会让预渲染缓存整体换键一次，须事先经用户确认；取消 Electron 迁移不改变像素基线。
- 原三期的第 0 步（Electron 离屏 paint 验证）随迁移计划取消，不再安排。
- 二期的第一步（建共享目录）风险低，人手有余时可以提前到一期并行。
