## 2. 阻塞项
1. **探针宿主页模块加载环境不符**：`scripts/probe-card-costs.mjs` 的宿主页写死了 `await import('/src/cards/index.ts')`，在 `vite preview` 的构建产物中，`/src/` 下的文件已被打包，无法直接 import，探针将直接 404 挂掉，仅补 `configurePreviewServer` 跑不起来。
2. **成本记录 mode 字段导致覆盖**：任务书要求补 `mode: 'dev'|'build'`，但 `server/costs-store.mjs` 中 `keyOf` 仅凭 `identityKey + device` 去重，未收纳 `mode`。导致 `dev` 和 `build` 记录互相覆盖，K2 “只认 build” 无从谈起。
3. **单测缺乏 DOM 环境**：要求在 `src/render/snapshotFreeze.test.mjs` 中对 `INHERITED_PROPS` 进行 DOM 元素级别的单测，但现有 `package.json` 的 `npm test` 是无头 Node 测试，未配置 `jsdom` / `happy-dom`，单测会因 `document` 不存在而报错。
4. **缺失单卡位图快照比对脚本**：要求进行 “差异内联前后 captureSnapshot 位图逐像素比对”，但当前仅有整视频比对脚本 `verify-unified-frames.mjs`，无针对单卡快照的现成比对工具，执行者将卡在此步。
