开工指令：`docs/plan/release-019-020-kickoff.md`。两版都已发出、部署上线、官网换版。

## 五、安全专审

退出后逐项撤回涉及账号、作废与退出确认、文档服务同步、跨服务通知，按开工指令过了专门的 Opus 对抗性专审（报告 `docs/archive/agent-reports/AGENT-claude-sec-logout-rollback.md`）。**查出 5 条，全部修掉并有反例测试守着**：

| 编号 | 是什么 |
|---|---|
| SEC-01 | 补偿操作号可被页面提交占号，撤回永久卡死、用户的退出一直办不完；事件号还随广播泄给同项目成员 |
| SEC-02 | `isIdList` 只判「是不是字符串数组」，普通数组的改动既不撤也不记保留 |
| SEC-03 | 冲突判定 O(n²) 且同步跑，16000 项冻住事件循环 28.3 秒，区间大小由被踢的会话自己决定 |
| SEC-04 | 一个账号的撤回卡住会挡住同实例别的账号登记结束见证 |
| SEC-05 | 账本里记的路径没有长度上限，一次退出可塞约 1 MB 进单行 JSON 账本 |

主会话亲自复跑确认：改之前 5 条反例测试 **0 过 5 失败**，改之后在 759 条受影响测试里全绿。专审同时否掉了五个方向（伪造或重放撤回证明、撤回范围被撑大、页面连接串台、泄露、同一次撤回落地两次），其中「页面串台」主会话独立查到同一结论。

主会话另外改掉一处**不是专审查出的**：超出上限没撤的几处原本被算进网页上「M 处已被别人接着改过，保留」——那对用户是假话，会让人以为同事覆盖了自己的改动。现在三个数分开报、分开显示。

## 七、没做成的与待办

- **清单里 31 项 `[在节点上做]` 的远端验收项**未逐条重做，记未跑；两版都用生产站点只读检查取得实证（`ok: true`、`fails: []`，手机与桌面两侧页面错误 0、失败请求 0），并核对线上前端与本机构建逐一致、节点健康检查版本号正确、`render.code-version match: true`。
  - 其中 **S3-r3** 主会话实际试跑过（`c10-browser-probe --site https://visuhive.com --stage-origins https://s1.visuhive.com,https://s2.visuhive.com`）：**跑不动**，原因是这支探针为跨机场景设计，要一个带鉴权的协调口（`PUT c10b.latest` 回 **401**），且「创建者开启多用户协作放云端」报「连不上云端，设置没有完成」。不是产品故障，是前置条件（协调口令牌、已登录账号）没配。要做这一项得先把那套配置准备好。
  - 其余远端项多为节点上的人工流程（装服务、改 nginx、杀进程、真模型端到端），不是能从本机一条命令跑完的，按未跑记录。
- **真机核对清单**（iPhone/iPad Safari 的崩溃重载、真安卓的进程隔离、窄屏气泡位置）需要真设备，记待用户项。安卓模拟器那几步主会话亲自做了，并由此查出一条代码问题（见下）。
- **安装包冒烟、补丁演练**按用户 2026-10-22 定，记待办，不挡发版。
- **「速度」入口**（前置项之一）按用户要求排在最后且不先进 main，等用户审〔裁〕，未做。
- 剪辑段里的转场与素材效果卡节点照旧不出流；从剪辑段中间起播时整段先被抑制、露沙漏 0.3～0.7 秒（原有行为）。

## 八、这次查出并记进 TODO 的既有问题

都经主会话实测确认**不是这两版引入的**：

- **舞台闸门判安卓只看 `userAgentData.platform`，非安全来源下保护失效**（安卓模拟器实测：`http://10.0.2.2` 下 `isSecureContext:false`、两个属性都不存在；经 `adb reverse` 走 `localhost` 后报 `deviceMemory:4`、`platform:"Android"`）。生产走 HTTPS 不受影响。
- **舞台端口白名单拦掉正当的 `/@media/<hash>`**（合并前提交上同样失败）。
- **渲染队列「plan 切分完、细任务全部落定」等不到**（合并前提交上同样失败；`claim-gate`、`S3-1`、`c10-browser-full` 的 A5 同一族）。
- **长 id 数组的批量增删是平方级**（`json-ops.mjs`，16000 片段上撤 16000 处要 11.7 秒；页面提交走同一条路）。

## 九、过程中踩的坑（已写进 `docs/local.md`）

- **Windows 路径分隔符一天坑了三次**：账号测试的两个环境变量必须用反斜杠；`logout-rollback-probe` 的 `--site` 因 `path.join` 回反斜杠而把所有请求判成 404；部署清单按目录取漏掉根目录的 `package.json`，导致线上代码新了版本号还是旧的。
- **退出码 0 不等于跑完**：全量测试两次出现退出码 0 但日志只有几十 KB、没有汇总行的假通过。判据取汇总行与日志大小。
- **守门测试扫到构建产物**：`desktop/src-tauri/runtime/` 是 gitignore 的产物，锁文件守卫把那份副本判成第二处引用。已修并做反证（塞词进被跟踪文件→立刻变红→还原后全过）。
- **多会话共用仓库时不能用 `git add -A`**：曾把另一个会话在途的 `.claude/launch.json` 卷进提交，已退回。
- **「出包前锁提交」还不够**：锁定与构建之间仍有窗口，0.7.20 就被一个纯文档提交插队。以后在构建脚本开头核对 HEAD 等于锁定值。
