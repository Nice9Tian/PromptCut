# PromptCut 0.5 期声音：实现与验证

日期：2026-10-05。基于 main `f951553cc9f1bd8507f50c0e840a2b96eac25ad8`，仅交付 `Doger`，不合入 main、不发版、不部署。

## 已实现

- 原生提示音与合成键盘声：完整参数、固定种子、版本化配方、字素事件表、48 kHz 采样及随机访问。中文、组合字符、emoji、标点、空白和停顿使用同一时间表。
- 独立音效：浏览器 Worker 按块生成 WAV，经正常素材分片接口入库，素材服务只保存字节。完整配方与内容哈希持久化，页面或 Agent 关闭后不依赖临时 blob。
- 动效卡可以同时写视觉 `Component` / `card()` 与确定性的 `audio()`。声音 WAV 归同一视觉片段所有，画面保留；不额外创建可重复发声的音频段。新增 `av-pulse` 声画示例。
- 卡片声音和普通素材均可独立静音，画面不变；时间轴常驻「已静音」徽标，窄片段有外置图标，行头显示静音数量。恢复片段声音不解除序列静音。
- 内嵌声音的动效卡禁止分离音轨，返回 `EMBEDDED_CARD_AUDIO_UNSEPARABLE` 并在界面显示失败原因；混合多选先全部校验，失败不创建空轨、不部分修改。普通视频音轨分离仍保留。
- 生成、调参、取消和进度接入现有 Agent 与参数面板。Agent 等到入库、提交结束才返回，保留编辑归属与撤销语义。
- 源码、上游源码、参数、事件、种子和范围参与身份。成功入库且项目/片段未变化才切换；失败、取消、过期任务不覆盖旧引用。缓存复用先检查当前素材服务是否仍有 WAV 字节。
- 移动、裁切、切分保留源偏移；普通素材导出中的毫秒舍入不再用于合成音效。缺失/过期声音明确失败，不悄悄导出缺声成片。

完整测试命令：

```sh
HOME=<可写测试目录> PUPPETEER_EXECUTABLE_PATH=<Chromium路径> npm test -- --test-concurrency=4 'server/test/*.test.mjs' 'src/**/*.test.mjs' 'tools/report-worker/*.test.mjs'
node --experimental-transform-types scripts/probes/sound-effects-probe.mjs --node-only --av
```

资源测量：独立合成内核的 60 秒、10000 个稀疏事件，生成 11520044 字节 WAV，本次约 2.86 秒、最大块约 20.4 ms、进程峰值 RSS 231.5 MB。该配方约 1.43 MB，因此不能通过持久化工作流预算；这不是 UI 支持 10000 事件入库的承诺。

持久化预算：单配方/声音身份 96 KiB、项目差异提交 224 KiB，避免触发大项目根替换而覆盖并发编辑。超限明确要求拆分或精简。原生合成最多同时 64 个事件，10000 个同时敲击的请求在分配前拒绝。64 个重叠事件的本次内联合成最大块约 25.1 ms，取消状态更新约 0.13 ms。浏览器 Worker 的真实调度延迟仍未实测。

## 未通过或未测试，不能表述为全量验收完成

- 现有全量基线仍有 85 项失败，集中于云环境的网络接口/局域网、Chrome、FFmpeg 选项和服务启动等路径。最终失败名称均出现在初始基线，不代表这些问题可以忽略。
- Linux Chromium 进程在浏览器启动阶段遇到 ProcessSingleton `socket() EPERM`。两项仓库画面基线命令已实际尝试，均在启动前失败，未获得像素比较结果。云浏览器打开本地开发地址也被客户端阻止，没有绕过限制。
- 官方 headless-shell 的下载连接超时。因此真实 Chromium 预览、暂停/恢复/seek 的浏览器行为、Chrome `OfflineAudioContext/renderMix`、在线 `browserExport` 与静音徽标截图均尚未通过实际浏览器验证。
- Windows 桌面、用户笔记本性能门槛、人工试听、物理声卡/设备延迟未测试。跨平台 PCM 阈值未验收。
- MP4 样本使用纯色测试画面，只用于验证音频编码、混音和定位；不是编辑器画面渲染的录像。
- 任意自定义 `audio()` 回调可能执行昂贵同步代码；其取消响应没有可证明的上界。卡片作者仍须及时返回并使用按块计算。原生预设的确定性和资源预算已单独验证。
- 持久配方保存字素事件；视觉对当前文字使用运行环境的 Unicode 分词。不同 Unicode 引擎版本仍需跨浏览器复核。

## 验收材料与后续

`scripts/probes/sound-effects-probe.mjs` 可重现测试项目、WAV、MP4、资源与事件对账 JSON。默认尝试真实浏览器路径；`--node-only` 明确只运行 Node/HTTP/FFmpeg 路径；加 `--av` 覆盖声画同片段。

先在可运行 Chromium 的环境跑默认浏览器探针、`scripts/verify-determinism.mjs` 和 `scripts/verify-unified-frames.mjs`，再测 Windows、听样本并确认音色。`Doger` 保留供审阅；是否合入 main 由用户决定。旧音频重构计划未被替代。
