## 6. 与设计稿不一致之处

- 每个 Agent 对话一条连接，不是共用一条：写入身份只能从握手取得。
- 页面经 `POST /api/agent/bind` 告诉服务端当前的项目和文档服务；没绑定之前，一切照旧。
- 5 个工具（`set_project_meta`、`switch_cut`、`add_cut`、`remove_cut`、`attach_clip_motion`）拆开：写入在服务端执行，只向页面要一次页面状态。
- 页面状态（播放头、选区、总时长的手动值）由页面收到远端改动后自己推出来。
- 实体粒度改为每个顶层字段一个实体（`/meta/fps`、`/meta/style` 等）。
- 超过 256 KiB 的写入走 `project.upload`。
- 局域网模式要以 `PROMPTCUT_LAN_HOST=1` 重启编辑器：页面给出命令和复制按钮；一键重启留给 C10 和桌面壳。
- codex、agy 两路拿不到 `callId`，它们的调用只能在 Agent 操作记录里撤。
