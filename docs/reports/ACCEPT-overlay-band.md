# 验证记录：时间轴上的叠加带

对应改动：把挂在片段上的东西（滤镜、像素映射、音频效果、素材效果卡）收成「叠加卡」，
在时间轴上画成片段里的一条带，并接上右键菜单那一支。

改到的是编辑界面（`src/editor/timeline/`），不是渲染管线、舞台、快照或导出取帧，
所以按 `docs/semantics/guide_files/verification.md`「按改动范围验证」不跑渲染附加项（G0-R）。

以及片段短下去的四档。
