# 约束

改本仓库时必须守的硬性规定。索引见 `../developer_guide.md`。

- **分层**：kernel ← render ← editor / mcp / ai，下层不引用上层，守门测试会拦。
- **卡片**：卡片代码遵守 `server/card-authoring-guide.md` 里的硬约束。
- **用词**：文档和注释里说「预渲染」「生成快照」，不说「烘焙」「冻结」。代码标识符不受限。
- **提到文档写文件名**：不用编号简称，新建文档不加数字前缀。
- **不碰用户在跑的东西**：用户常驻的编辑器、桌面版的运行时副本、用户数据目录只读不写；不结束不是自己启动的进程。
- **新增费用要绕，不停**：换机型、加带宽、租外部服务等新增费用不由会话发起，也不得以此为由停下：先找不花钱的路；实在绕不过就记为「待用户项」写进报告，继续其它工作。需要人在机器旁的物理操作同此办理。
- **release 永远可用**：`release` 分支任何时候都指向一个能构建、能运行、能使用的完整版本。只从 main 前进；每次功能合入 main 后立刻判一次，暂停或交接前必须判一次；合入条件与操作见 `git_and_release.md`「release 分支」。
- **不动宿主机的网络**：任何会话、子 Agent、辅助节点都不得禁用或断开网卡、WiFi，不得改系统代理、路由、DNS、防火墙来制造故障。模拟断线只在应用层做：经代理掐连接、在服务器侧断那条 TCP、用测试钩子断传输。动了宿主机网络，会话自己就失联，没人能把它恢复。
- **不原地改 store 里的项目对象**：共享项目靠对象身份判断改动，原地改会让同步看不见；改动一律换新对象。
- **本机信息不进仓库**：只和这台机器有关的环境信息（磁盘、本机工具的怪癖、账号与密钥的位置）写在 `docs/local.md`。该文件不入库，可能不存在。
