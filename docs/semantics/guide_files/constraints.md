# 约束

改本仓库时必须守的硬性规定。索引见 `../README.md`。

- **分层**：kernel ← render ← editor / mcp / ai，下层不引用上层，守门测试会拦。
- **卡片**：卡片代码遵守 `server/card-authoring-guide.md` 里的硬约束。
- **用词**：文档和注释里说「预渲染」「生成快照」，不说「烘焙」「冻结」。代码标识符不受限。
- **提到文档写文件名**：不用编号简称，新建文档不加数字前缀。
- **release 就是最近一次发布的版本**：`release` 分支指向最近一次正式发布的版本，任何时候都能构建、能运行、能使用。只从 main 前进，**只在发版时合入**；平时 main 走多远，`release` 都留在上一个发布版上。合入条件与操作见 `git_and_release.md`「release 分支」。
- **测试和探针的写法**：断线只在应用层模拟——经代理掐连接、在服务器侧断那条 TCP、用测试钩子断传输；不去改网卡、系统代理、路由、DNS 或防火墙。Windows 下脚本启动子进程设 `windowsHide: true`（PowerShell 用 `-WindowStyle Hidden`），整条子进程链都要设，别把终端窗口弹到前台。
- **不原地改 store 里的项目对象**：共享项目靠对象身份判断改动，原地改会让同步看不见；改动一律换新对象。
- **本机信息不进仓库**：只和这台机器有关的环境信息（磁盘、本机工具的怪癖、账号与密钥的位置）写在 `docs/local.md`。该文件不入库，可能不存在。
