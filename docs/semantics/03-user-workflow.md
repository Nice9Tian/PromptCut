# 用户工作流程

本文写用户从打开软件到拿到成片的流程，以及每一步系统必须提供的功能。功能挂在它服务的步骤下面。

## 三种工作方式

用户在同一个项目上可随时切换三种方式，切换不丢状态：

| 方式 | 界面 | 谁在动手 |
|---|---|---|
| **传统式** | 左栏（素材、动画、特效、编辑、字幕）+ 预览 + 时间轴 + AI 栏 | 人为主，Agent 随时可插入 |
| **对话式** | 只有预览 + AI 栏 | 人说，Agent 做 |
| **SKILL** | 本软件缩成悬浮窗，只看不改 | 外部桌面 Agent（Claude Code / Codex）在独立任务目录里改一份副本 |

SKILL 方式：开始时快照项目、起一份无头实例、拉起桌面 Agent 的对话；Agent 通过只读链接看画面；结果三方合并回项目；用户随时能收回控制，收回后 Agent 的任何写入不再落地。

## 主线流程

### 0. 开始

- 开始页：新建空项目；打开本地草稿；打开 `.proc`（项目）或 `.procp`（项目 + 素材打包）。
- 拓展功能的状态与安装：听写、镜头识别、运动追踪、主体检测、素材收集、配音。装没装只影响对应能力的档位，不影响主线。
- 草稿自动保存在本机，开始页可列出、打开、删除。

### 1. 备料

用户把素材放进项目，或让 Agent 去找。

- 导入本地视频、图片、音频；导入 `.srt` / `.vtt` 字幕稿挂到素材上。
- Agent 从网页链接抓取视频（含站内搜索、探测、登录态），从网页找图片直链导入，或把用户在对话里发的附件导入。
- 配音：把文字合成为语音进素材库，可直接放到时间轴。
- 素材理解（人和 Agent 共用同一份结果）：语音转写、镜头切分、主体位置、点运动轨迹。这些结果存在素材上，重复使用不重跑。
- 从视频派生「只有声音」的素材；音画分离。

### 2. 下指令

- 用户在 AI 栏用自然语言说要什么，可以附文件，可以从预览里右键把某张卡「引用到 AI」。
- 选 Agent 的提供方：本机的 Claude Code、Antigravity、Codex 命令行，或直连模型接口。
- 一键配特效：对一段素材自动走完「转写 → 切段 → 配动效卡 → 铺字幕」。
- 分工模式：多个角色（制片主管、剪辑导演、特效助理、素材收集员）按序接力。
- 多 Agent 并行：AI 栏可开多页，每页一个 Agent，各自声明改动范围、互发消息协调。

### 3. Agent 剪辑

Agent 读项目、看画面、改项目。系统必须提供：

- **读**：项目全貌、素材清单、当前选中、卡片清单与参数、部件库、序列、剪辑版本、布局与实体框。
- **看**：按时刻渲染整屏或单卡；按镜头拼图看素材；整段动效的 8 帧动图。
- **改时间轴**：加、改、删、复制、切分片段；序列的增删、改名、隐藏、静音、锁定、排序；片段跨序列移动；转场（交叉溶解、淡入、淡出，绑组）；总时长。
- **改卡**：参数；位置（坐标、矩形、对齐、微调）；不透明度、淡入淡出；强调（阴影、描边）；三维透视；跟随运动轨迹；组合卡的部件增删改移。
- **效果**：滤镜库（整帧调色）、像素映射（逐像素选区）、音频效果库，都是「建一个、挂多段、改一处全变」。
- **音频**：音量、响度测量、音画分离、配音。
- **字幕**：一张字幕卡装整段，整份灌入，单条增删改。
- **建卡**：读建卡规则、新建、读源码、局部改、看渲染出的 DOM。建卡是最后手段。
- **保护**：删片段、删序列、删效果有门槛，越过要说明理由，理由用户可见；Agent 不能绕过工具直接改。

### 4. 看结果

- 预览显示时间轴某一刻的画面，播放、暂停、拖动。
- Agent 的回复默认不显示正文，用户看到的是它交上来的进度条目（做了、待办、问题）和操作详细预览（看过的图、改动前后的动图、参数差异）。
- Agent 需要用户做事时停下并说明，不继续改。

### 5. 修正

用户可以再说一句，也可以自己动手：

- 时间轴：拖动、改时长、切分、换序列、吸附、序列换序、多条剪辑版本切换。
- 预览：选中、移动、改文字、右键引用或删除。
- 编辑分区：参数表单、约定封装的代码页、节点图。
- 字幕：时间轴上逐条拖、改时长、双击改字。
- 撤销、重做。

### 6. 交付

- 导出视频：成片，以及只含卡片的透明层；可取消；可打开产物目录。
- 保存项目 `.proc`；打包保存 `.procp`（连素材，换机器直接打开）。
- 只读查看链接：能看不能改。

## 主线之外

- 项目设置：名称、画幅比例与方向、帧率、分辨率、主题。
- 皮肤（界面外观）。
- 诊断报告：对话出问题时导出给开发者。
- 打开旧项目时的一次性迁移提示（素材分类、已停用的 Python 卡）。
