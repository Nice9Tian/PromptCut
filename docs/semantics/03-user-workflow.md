# 用户工作流程

本文写用户从打开软件到拿到成片的流程，以及每一步系统必须提供的功能。功能挂在它服务的步骤下面。

## 两种工作方式

用户在同一个项目上可随时切换两种方式，切换不丢状态。两种方式都是人与 Agent 协作，区别在 Agent 从哪里接入、编辑界面是否打开。

| 方式 | 界面 | 谁在动手 |
|---|---|---|
| **传统式** | 打开编辑界面：左栏（素材、动画、特效、编辑、字幕）+ 预览 + 时间轴 + AI 栏。左栏和时间轴可收起，收起后只剩预览和 AI 栏 | 用户和 AI 栏里的 Agent（CLI 或 API 接入） |
| **SKILL** | 默认关闭编辑界面，软件转入后台运行 | 桌面 APP 里的 Agent（Codex、Claude Code 等）；用户可随时打开界面一起改 |

SKILL 方式下的桌面 APP Agent：

- 通过 MCP 接入本软件，权限与 AI 栏里的 Agent 相同。
- 桌面 APP 的每个会话是一个独立的 Agent。打开编辑界面时，每个会话在 AI 栏里单独显示，标明所属厂商和正在进行的操作。
- 用户手动修改时，桌面 APP Agent 和 AI 栏里的 Agent 一样收到通知。
- 本软件拿不到桌面 APP Agent 的文字输出。它按 SKILL 提示词约定的结构化方法汇报进度（如阶段完成、全部完成），显示方式与 AI 栏里 Agent 的进度条目相同。

## 后台运行

- 关闭编辑界面不退出软件：软件转为托盘图标和悬浮窗，继续在后台运行。
- 点击托盘图标或悬浮窗重新打开编辑界面。
- 只有在托盘图标或悬浮窗上右键选择关闭，软件才退出。

## 主线流程

### 0. 开始

- 开始页：新建空项目；打开本地草稿；打开 `.proc`（项目）或 `.procp`（项目 + 素材打包）。
- 拓展功能的状态与安装：听写、镜头识别、运动追踪、主体检测、素材收集、配音。装没装只影响对应能力的档位，不影响主线。
- 草稿自动保存在本机，开始页可列出、打开、删除。

### 1. 前期准备

用户把素材放进项目，或让 Agent 去找。

- 导入本地视频、图片、音频；导入 `.srt` / `.vtt` 字幕稿挂到素材上。
- Agent 从网页链接抓取视频（含站内搜索、探测、登录态），从网页找图片直链导入，或把用户在对话里发的附件导入。
- 配音：把文字合成为语音进素材库，可直接放到时间轴。
- 素材理解（人和 Agent 共用同一份结果）：语音转写、镜头切分、主体位置、点运动轨迹。这些结果存在素材上，重复使用不重跑。
- 从视频派生「只有声音」的素材；音画分离。

### 2. 核心制作

**用户发送指令**

- 用户用自然语言说要什么，可以附文件，可以从预览里右键把某张卡「引用到 AI」。
- 选 Agent 的接入方式，分三类：
  - **CLI**：本机的命令行 Agent（Claude Code、Antigravity、Codex 等），在 AI 栏里对话。
  - **桌面 APP**：本机的桌面 Agent 应用（Claude Code、Codex 等），经 SKILL 方式接入，在它自己的窗口里对话。
  - **API**：直连模型接口，在 AI 栏里对话。
- 选创造力等级，决定 Agent 能改到多深。每个对话各一档，默认「高」：
  - **低**：只用已有的卡片和效果，只改参数；测量只用内置方法。
  - **中**：在已有卡片和效果的基础上，可以改它们的代码或表达式，但不新建。
  - **高**：可以新建任意卡片和效果，可以写自定义测量代码。
- 多 Agent 并行：AI 栏可开多页，每页一个 Agent。一个主 Agent 也可以拉起其它 Agent 并给它们分派任务，拉起时可以给它们附加预设的角色。各 Agent 声明各自的改动范围，互发消息协调。

**Agent 执行**

Agent 读项目、看画面、改项目。下列是系统至少要提供的能力和默认方法，不是封闭的清单。其中改卡片代码、新建卡片、新建或改写效果、自定义测量，按当前对话的创造力等级开放，见「用户发送指令」。

- **读**：项目全貌、素材清单、当前选中、卡片清单与参数、部件库、序列、剪辑版本、布局与实体框。
- **看**：按时刻渲染整屏或单卡；按镜头拼图看素材；整段动效的 8 帧动图。
- **改时间轴**：加、改、删、复制、切分片段；序列的增删、改名、隐藏、静音、锁定、排序；片段跨序列移动；总时长。
- **改卡**：参数；位置（坐标、矩形、对齐、微调）；不透明度、淡入淡出；强调（阴影、描边）；三维透视；跟随运动轨迹；组合卡的部件增删改移；卡片本身的代码（JS、CSS、HTML），可读取后局部修改，不限于已暴露的参数。
- **建卡**：读建卡规则、新建卡片、看渲染出的 DOM 并对应到源码行。
- **效果**：转场（交叉溶解、淡入、淡出；在时间轴上显示，并把相关片段绑成一组，但不属于时间轴）；滤镜库（整帧调色）、像素映射（逐像素选区）、音频效果库。库类效果定义一次即可挂到多段，改定义时挂着它的各段一起变；为某一段单独建一个也可以。
- **音频**：音量；测量（响度测量是内置的默认方法，Agent 也可以用 JS 自定义测量方法）；音画分离；配音；音频效果（见「效果」）。
- **字幕**：一张字幕卡装整段，整份灌入，单条增删改。
- **保护**：
  - 破坏性操作有门槛：删片段、删序列、删效果时要说明理由，理由对用户可见。
  - Agent 之间不悄悄互相覆盖：一个 Agent 改到别的 Agent 正在改或刚改过的内容时，双方都要知道。
  - 用户正在编辑的内容要让 Agent 知道：Agent 看或改用户正在编辑的卡时，系统在返回里直接标出「用户正在编辑」（例如看画面、读卡片的返回），避免它覆盖用户的编辑。这是提示，不是禁止，因为用户可能正是在这个位置给 Agent 下指令。
  - Agent 需要用户做事或回答时，停下并说明，不继续改。
  - Agent 不能绕过工具直接改项目。

### 3. 用户实时查看

- 预览显示时间轴某一刻的画面，播放、暂停、拖动。
- Agent 的文字回复不显示，桌面 APP Agent 的文字输出本来也拿不到。用户看到的是 Agent 交上来的进度条目（做了、待办、问题）和操作详细预览（看过的图、改动前后的动图、参数差异）。

### 4. 用户交互修正

用户可以再说一句，也可以自己动手：

- 时间轴：拖动、改时长、切分、换序列、吸附、序列换序、多条剪辑版本切换。
- 预览：选中、移动、改文字、右键引用或删除。
- 编辑分区：参数表单、约定封装的代码页、节点图。
- 字幕：时间轴上逐条拖、改时长、双击改字。
- 撤销、重做。

### 5. 交付

- 导出视频：成片，以及只含卡片的透明层；可取消；可打开产物目录。
- 保存项目 `.proc`；打包保存 `.procp`（连素材，换机器直接打开）。
- 只读查看链接：能看不能改。

## 主线之外

- 项目设置：名称、画幅比例与方向、帧率、分辨率、主题。
- 皮肤（界面外观）。
- 诊断报告：对话出问题时导出给开发者。
- 打开旧项目时的一次性迁移提示（素材分类、已停用的 Python 卡）。
- 一键配特效：对一段素材自动配好字幕和动效卡。它是入门时的测试和展示功能，不属于核心功能。
