# 编辑界面：查看与修正

展开 `../user-workflow.md` 主线的第 3 步「用户实时查看」和第 4 步「用户交互修正」，以及编辑界面本身。从属于 `user-workflow.md`，与它冲突时以它为准。

## 编辑界面

- 左栏（素材、动画、特效、编辑、字幕）+ 预览 + 时间轴 + AI 栏。
- 左栏和时间轴可收起，收起后只剩预览和 AI 栏。
- 皮肤：界面外观可切换。
- 界面风格：整体圆角；遵循 Microsoft Fluent Design 规范的现代深色生产力工具风格；主题色是高饱和度的青蓝色和低饱和度的酱紫色。

## 手机版界面（2026-10-21 用户定）

- 身份为手机的在线浏览器用手机版界面，交互以 `prototypes/mobile-ui-demo/` 的演示稿为准（用户 2026-10-21 过目确认）；名词见术语表。
- 底部导航栏三个分页：缩略预览、时间轴、Agent。缩略预览是默认页：预览居中，下面是播放条、缩略时间轴和子导航栏；时间轴分页展开完整时间轴；Agent 分页是对话。
- 缩略时间轴只放主要内容，各卡等宽、标时长，正中是当前帧标记；点卡选中，先选中再长按拖动换顺序。点转场和点卡是同一个动作。没有视频、图片、剪辑段时，卡片段也显示出来；任何项目都要显示得出东西，开始时刻与结尾时刻都有缩略图（2026-10-23 用户定，原话「这个不是主要功能，先跑通（能显示出来东西，开始时间-结尾时间都有缩略图）」）。取法见 `../mechanism/platforms.md`「手机版缩略时间轴的主要内容」。
- 选中一项后，子导航栏第一个是「引用」，点了切到 Agent 并带上引用标记。
- 完整时间轴可以用「−」「＋」「适应宽度」和双指捏合缩放，进入时默认适应宽度。
- 有待合并项时，顶栏下方显示冲突横条，右侧「处理」打开冲突合并窗口（同桌面的「冲突合并」）。
- 返回层级：分页 → 缩略预览 → 项目列表；浏览器后退同一规则。
- Agent 分页照演示稿重画（2026-10-21 用户定：Agent 分页另开一项、先做；2026-10-22 用户定：「你派子Agent来做」；样式与交互以演示稿 Agent 页为准，不再是桌面那套云端对话页挤进手机宽度）：
  - 上面一排对话标签：每个会话一个标签（界面上叫 Agent 1、Agent 2……），每个都带「✕」可关，右边「+」新开一个；标签清单和桌面共用同一份（按项目分开、内部标记是「项目ID_AgentID」、编号取最小空号，见上面「AI 栏的 Agent 标签」）。标签行下面一行：「创造力」低 / 中 / 高（只管这个对话，缺省跟项目），右边是「共有对话 / 私有对话」小标签；再下面是消息，底部是输入区。
  - 消息：我的话在右边、Agent 的话在左边；Agent 每一轮的操作画成一张「Agent 操作」卡片，标题是「第 N 轮 · M 项操作」，每一项标完成 / 失败 / 在做 / 还没做，本轮或阶段小结的已完成、待办、问题接在同一张卡片里；最新一轮和还在做的一轮默认展开，其余折叠，点标题展开或折起；还在做时消息末尾是三个点和「正在做什么」。
  - 引用（用户 2026-10-22 定：「引用」不再往输入框里插「@卡片 名字(片段 id)」这串字，改成演示稿里输入框上方的标记条，发送时照样把引用带给 Agent）：点「引用」切到 Agent 分页，输入框上方出现引用标记条，一项一个标记「@ 名字」，带「✕」可去掉；同一项重复引用不重复放；输入框里不插字，提示变成「@名字 想怎么改?」；发送时引用连同话一起发给 Agent（正文里仍写成「@卡片 名字(片段 id) 」放在话的前面，Agent 认的是这个写法），发出后标记条清空，没发出去就放回；发出的消息上，开头的引用画成标记。
  - 没有会话时是开始页，规则同桌面（用户 2026-10-22 定，原话见上面「没有会话时显示开始页」）：只有一项标签「开始」（没有「✕」），消息区是预设「做一个动画告诉我使用软件可以干什么」，下面是平时的输入框；刚进项目、没被手动清空过时带引导动画，手动清空过只有预设和输入框；点预设把句子放进输入框、发送钮闪动；点发送才建第一个会话（Agent 1），这条消息在里面发出。
  - 〔裁：2026-10-22 mobile-agent-page〕每个会话的对话在切走后照跑（和桌面一样每个会话各挂一份）；关一个有对话的会话前先问一声（手机版没有历史对话列表，关掉之后这段对话在手机上不再显示，仍留在云端的对话历史里，桌面版找得到），空会话直接关。
  - 〔裁：2026-10-22 mobile-agent-page〕演示稿输入框上方那排快捷提问（标题更大气、加转场、配乐、剪快点）保留，点一下把这句话放进输入框、不直接发送（演示稿是点了就发，改成不直接发，免得点错就用掉额度）；开始页上不放（那里有预设）。
  - 〔裁：2026-10-22 mobile-agent-page〕有消息在跑、输入框又是空的时候，发送钮换成停止钮；输入框里有字时仍是发送（云端账号模式下排在前一轮后面）。已有对话、对话权限还没读回来时先不让发（对话可能是别人的私有对话），新对话不用等。
  - 〔裁：2026-10-22 mobile-agent-page〕演示稿里有、业务层没有对应的不显示：Agent 需要你确认的破坏性操作确认卡、操作卡片里「改动前后」对比图和参数差异；业务层有、演示稿里没有的入口手机版暂不放：附件、模型与思考强度、历史对话列表、删除对话、诊断报告、操作卡片里的「撤销这步」、Agent 未读角标（见任务报告「没做到的与原因」，等用户定要不要补）。

## 用户实时查看

- 预览显示时间轴某一刻的画面，可播放、暂停、拖动。
- AI 栏显示 Agent 的进度条目和操作详细预览：看过的图、改动前后的动图、参数差异。

## 用户交互修正

用户可以再发一条指令，也可以自己动手：

- 时间轴：拖动、改时长、切分、换序列、吸附、序列换序、多条剪辑版本切换。
- 剪辑标签（2026-10-20 用户定）：时间轴上方为每条打开过的剪辑留一个标签，点标签切换激活的剪辑。标签不会因为失去焦点或点了别处而消失，一直留着，直到用户点标签上的「×」关掉；「×」只关标签，不删剪辑。最后一个标签不能关。删除剪辑在素材库里做。
  - 剪辑的入口只有素材库的「剪辑」组和这一栏标签两处；双击标签改名，标签栏末尾可以新建剪辑；双击时间轴上的剪辑段，在标签栏里打开并激活它引用的剪辑。剪辑被删掉（包括协作同伴或 Agent 删的）时它的标签自动消失（〔裁：Argon 审 2026-10-20〕：撤掉左侧竖栏的剪辑组，改名、新建分到这两处；补双击剪辑段与标签自动消失）。
  - 打开了哪几个标签是这台设备上的界面状态：刷新、重开项目后恢复，不随项目同步给别的成员（〔裁：Argon 审 2026-10-20〕：任务书原写在三级，按「用户看得到」拆出这一句放在这里，存法在 `../mechanism/project-model.md`）。
- 剪辑段的属性（2026-10-21 用户定）：选中剪辑段时，编辑分区可以改从被引用剪辑的第几秒开始，以及框、不透明度、淡入淡出、音量和静音；引用哪条剪辑不能改，要换就删掉这段，从素材库重新拖一条。打开被引用的剪辑：双击剪辑段，或在右键菜单点『打开剪辑』；编辑分区里也有『打开被引用剪辑』按钮。
- 片段速度（2026-10-23 用户定）：选中一个素材段时，编辑分区里有「速度」一栏，手机版在片段面板里。可以点常用倍率，也可以手动输入，
  范围 **0.25～4 倍**；超出范围**拒绝并提示**「速度要在 0.25～4 倍之间」，项目一点不改，不悄悄夹到边界。
  - 改了速度，这一段跟着变长变短：**变短**时挂在它上面的转场跟着缩短（短到装不下才拒绝这次改速度）；**变长**时推开后面的片段，
    推不开（后面的段在锁定的序列上，或推过去仍重叠）则**整个操作不生效并说明原因**，不截断、不部分生效。
  - 变速的声音会**变调**（2 倍高八度、0.5 倍低八度）；保调变速记在待办里。
  - 变速的素材段**可以**当音频素材效果卡的声音输入（2026-10-23 用户放开）；自带画面和声音的卡挂在变速段上也照常出声（2026-10-23 用户定）。

- AI 栏的 Agent 标签（2026-10-20 用户定，原话：「我发现Agent1那个会话没法删除。这个不符合预期。」；2026-10-22 用户改定，见下面三条）：
  - 每个 Agent 标签都可以关闭，包括第一个「Agent 1」和最后一个，悬停出「×」；关掉当前标签后切到相邻的标签。新建标签取当前最小的空号（关掉「Agent 2」后再新建得到「Agent 2」，不是「Agent 4」）。（2026-10-22 用户改定，取代 2026-10-20 的「只剩最后一个标签时不能关，保证 AI 栏总有一个标签」。）
  - 分页清单按项目分开（2026-10-22 用户定，原话：「不同项目的不共用一份，用户界面看到的是Agent1，Agent2.。。。实际上代码标记的是"项目ID_AgentID"。」）：每个项目有自己的一份 Agent 标签，切换项目就换成那个项目自己的那一份；界面上叫 Agent 1、Agent 2……，编号只在本项目内取最小空号；代码里标签的标记（存储的键、内部 id）是「项目ID_AgentID」。〔裁：2026-10-22 agent-tabs-start〕旧版本全局共用的那份清单不迁移、不读取（原样留在本机，不删）：各项目里的对话本身没有丢，在历史对话里找得到；项目文件自带的老对话（旧版本存进项目文件的那一段）补成该项目的「Agent 1」。
  - 没有会话时显示开始页（2026-10-22 用户定，原话：「所有Agent会话都可以关，可以全部清空，最后一个也可以关。如果没有会话，刚进项目自动创建一个开始页，使用动画引导用户在聊天框输入内容，或者点击预设的“做一个动画告诉我使用软件可以干什么”（点击以后把内容加入到编辑框，引导用户点击发送）。用户点击发送以后，再开始创建第一个Agent会话。例外如果用户手动清空了会话，不展示引导动画，只展示开始页（预设输入+编辑框）。」）：
    - 本项目一个会话都没有时（刚进项目，或用户把会话全关光了），AI 栏显示开始页：一个编辑框（平时的输入框）和一个预设按钮「做一个动画告诉我使用软件可以干什么」。点预设，这句话放进编辑框，发送按钮闪动，引导用户点发送。用户点发送之前不建会话、不发出聊天消息；点发送后才建第一个 Agent 会话（Agent 1），这条消息在里面发出；本机 Agent 和云端 Agent 都一样（云端是新建云端对话）。
    - 刚进项目、本项目从来没被用户手动关光过会话：开始页带引导动画，引导用户在输入框里写，或点预设。用户手动把会话关光之后（按项目记），这个项目的开始页不放引导动画，只有预设和编辑框。
    - 〔裁：2026-10-22 agent-tabs-start〕开始页在右栏竖栏里是一项「开始」（没有「×」），没有会话时「+」就是回到它；引导动画是一个呼吸的光点、指向输入框的向下箭头、输入框的描边脉动，克制，用现有深色与青蓝强调色；系统设了「减少动态效果」时动画全部关掉，只留静态描边；点预设后发送按钮闪动在两种开始页里都有（不是引导动画的一部分）；「手动关光过」记在本机浏览器里，不进项目文件、不同步给别的成员。
    - 手机版的 Agent 分页也用这份标签清单和这套开始页的规则，见上面「手机版界面」一节（2026-10-22 起，原先固定一页对话、没有开始页的做法作废）。
- 预览：选中、移动、改文字、右键引用到 AI 或删除。
- 编辑分区：参数表单、约定封装的代码页、节点图。
- 字幕：在时间轴上逐条拖动、改时长、双击改字。
- 撤销、重做。多用户协作时按撤销：要撤的那一步改过的地方之后没有别人再改，直接撤回；别人在它基础上又改过，弹出与暂时离线重连共用的「冲突合并」窗口（2026-10-18 用户定）：
  - **导航栏常驻入口**：只要存在待处理的冲突或待合并项，软件导航栏顶端就显示「冲突合并」按钮，用户随时可以打开处理；全部处理完后按钮隐藏。
  - **两级可勾选列表**：一级条目按被改的那样东西列，时间轴上的每个片段（卡片段、素材段、剪辑段）、每条字幕、每张卡片的源码、项目设置各算一条；展开到二级是它被改的各个属性，同一个属性改了几次只列一条，写明改成什么、云端现在是什么，例如「透明度 0.4 → 0.8（云端现在是 0.6）」；先改长度、又改透明度仍是两条（2026-10-22 用户定）。展开后可单独勾选其中某一项。
  - **顶端按钮**：「选中无冲突项」「取消全部勾选」。
  - **底部按钮**：「合并」（应用选中项）、「删除选中」（丢弃选中项），以及关闭按钮——当列表里还有可选项时显示为「下次再说」（关闭窗口并保留剩余项在顶栏「冲突合并」中），当没有任何可选项时变成「完成」（规则见 `../product/document-service.md`「冲突」）。
- 一次输入、一次拖动只算一步改动（2026-10-20 用户定）：在数字框里输入一个值，或拖一次滑块，只算一步改动、只记一步撤销，输入过程中的中间值不落进项目。数字框按回车或失去焦点时才算输入完成（输入过程中别人看不到，也不会同步出去），按 Esc 放弃；用方向键或框自带的上下箭头连续步进，也合并成一步。滑块拖动中画面可以实时跟着变，整次拖动（按下到松开）合成一步撤销。

## 片段声音（2026-10-05 用户确认）

- 带声音的动效卡片与普通音视频素材都可以单独静音或恢复声音，画面不受影响。
- 时间轴片段显示醒目的「已静音」标记；窄片段仍有常驻图标，序列行头显示静音数量或整条序列静音提示，不要求用户打开属性面板才能发现。
- 动效卡片的参数面板显示声音生成状态，可生成、重生成或取消；声音留在同一个视觉片段中。
- 对内嵌声音的动效卡执行音轨分离，界面明确显示失败原因，Agent 获得结构化失败。多选分离任一项失败，整批不修改。普通视频素材仍按原有流程分离。
