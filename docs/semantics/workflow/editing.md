# 编辑界面：查看与修正

展开 `../user-workflow.md` 主线的第 3 步「用户实时查看」和第 4 步「用户交互修正」，以及编辑界面本身。从属于 `user-workflow.md`，与它冲突时以它为准。

## 编辑界面

- 左栏（素材、动画、特效、编辑、字幕）+ 预览 + 时间轴 + AI 栏。
- 左栏和时间轴可收起，收起后只剩预览和 AI 栏。
- 皮肤：界面外观可切换。
- 界面风格：整体圆角；遵循 Microsoft Fluent Design 规范的现代深色生产力工具风格；主题色是高饱和度的青蓝色和低饱和度的酱紫色。

## 手机版界面（2026-10-21 用户定）

- 身份为手机的在线浏览器用手机版界面，交互以 `prototypes/mobile-ui-demo/` 的演示稿为准（用户 2026-10-21 过目确认）；名词见术语表。
- 底部导航栏三个分页：缩略预览、时间轴、Agent。缩略预览是默认页：预览居中，下面是播放条、缩略时间轴和子导航栏；时间轴分页展开完整时间轴；Agent 分页是对话。
- 缩略时间轴只放主要内容，各卡等宽、标时长，正中是当前帧标记；点卡选中，先选中再长按拖动换顺序。点转场和点卡是同一个动作。
- 选中一项后，子导航栏第一个是「引用」，点了切到 Agent 并带上引用标记。
- 完整时间轴可以用「−」「＋」「适应宽度」和双指捏合缩放，进入时默认适应宽度。
- 有待合并项时，顶栏下方显示冲突横条，右侧「处理」打开冲突合并窗口（同桌面的「冲突合并」）。
- 返回层级：分页 → 缩略预览 → 项目列表；浏览器后退同一规则。

## 用户实时查看

- 预览显示时间轴某一刻的画面，可播放、暂停、拖动。
- AI 栏显示 Agent 的进度条目和操作详细预览：看过的图、改动前后的动图、参数差异。

## 用户交互修正

用户可以再发一条指令，也可以自己动手：

- 时间轴：拖动、改时长、切分、换序列、吸附、序列换序、多条剪辑版本切换。
- 剪辑标签（2026-10-20 用户定）：时间轴上方为每条打开过的剪辑留一个标签，点标签切换激活的剪辑。标签不会因为失去焦点或点了别处而消失，一直留着，直到用户点标签上的「×」关掉；「×」只关标签，不删剪辑。最后一个标签不能关。删除剪辑在素材库里做。
  - 剪辑的入口只有素材库的「剪辑」组和这一栏标签两处；双击标签改名，标签栏末尾可以新建剪辑；双击时间轴上的剪辑段，在标签栏里打开并激活它引用的剪辑。剪辑被删掉（包括协作同伴或 Agent 删的）时它的标签自动消失（〔裁：Argon 审 2026-10-20〕：撤掉左侧竖栏的剪辑组，改名、新建分到这两处；补双击剪辑段与标签自动消失）。
  - 打开了哪几个标签是这台设备上的界面状态：刷新、重开项目后恢复，不随项目同步给别的成员（〔裁：Argon 审 2026-10-20〕：任务书原写在三级，按「用户看得到」拆出这一句放在这里，存法在 `../mechanism/project-model.md`）。
- AI 栏的 Agent 标签（2026-10-20 用户定，原话：「我发现Agent1那个会话没法删除。这个不符合预期。」）：每个 Agent 标签都可以关闭，包括第一个「Agent 1」，悬停出「×」；只剩最后一个标签时不能关，保证 AI 栏总有一个标签。关掉当前标签后切到相邻的标签。新建标签取当前最小的空号（关掉「Agent 2」后再新建得到「Agent 2」，不是「Agent 4」）。
- 预览：选中、移动、改文字、右键引用到 AI 或删除。
- 编辑分区：参数表单、约定封装的代码页、节点图。
- 字幕：在时间轴上逐条拖动、改时长、双击改字。
- 撤销、重做。多用户协作时按撤销：要撤的那一步改过的地方之后没有别人再改，直接撤回；别人在它基础上又改过，弹出与暂时离线重连共用的「冲突合并」窗口（2026-10-18 用户定）：
  - **导航栏常驻入口**：只要存在待处理的冲突或待合并项，软件导航栏顶端就显示「冲突合并」按钮，用户随时可以打开处理；全部处理完后按钮隐藏。
  - **两级可勾选列表**：每个一级条目是一个卡片，可展开到二级（该卡片的各次具体修改，如先修改了长度、又修改了透明度），展开后可单独勾选其中某一项。
  - **顶端按钮**：「选中无冲突项」「取消全部勾选」。
  - **底部按钮**：「合并」（应用选中项）、「删除选中」（丢弃选中项），以及关闭按钮——当列表里还有可选项时显示为「下次再说」（关闭窗口并保留剩余项在顶栏「冲突合并」中），当没有任何可选项时变成「完成」（规则见 `../product/document-service.md`「冲突」）。
- 一次输入、一次拖动只算一步改动（2026-10-20 用户定）：在数字框里输入一个值，或拖一次滑块，只算一步改动、只记一步撤销，输入过程中的中间值不落进项目。数字框按回车或失去焦点时才算输入完成（输入过程中别人看不到，也不会同步出去），按 Esc 放弃；用方向键或框自带的上下箭头连续步进，也合并成一步。滑块拖动中画面可以实时跟着变，整次拖动（按下到松开）合成一步撤销。

## 片段声音（2026-10-05 用户确认）

- 带声音的动效卡片与普通音视频素材都可以单独静音或恢复声音，画面不受影响。
- 时间轴片段显示醒目的「已静音」标记；窄片段仍有常驻图标，序列行头显示静音数量或整条序列静音提示，不要求用户打开属性面板才能发现。
- 动效卡片的参数面板显示声音生成状态，可生成、重生成或取消；声音留在同一个视觉片段中。
- 对内嵌声音的动效卡执行音轨分离，界面明确显示失败原因，Agent 获得结构化失败。多选分离任一项失败，整批不修改。普通视频素材仍按原有流程分离。
