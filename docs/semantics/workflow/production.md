## 用户发送指令

- 用户用自然语言说要什么。
- 可以附文件，本机与云端相同。〔用户 2026-10-07 定〕
- 可以从预览里右键把某张卡「引用到 AI」，让指令指向它。
- 发送前可以选 Agent 的接入方式，可以调整该对话的创造力等级。
- 云端 Agent 新对话默认共有，用户可主动设为私有。共有对话中，同项目所有已登录且有项目权限的成员可以查看历史、回复和发送；界面显示每条消息是谁发送的。私有对话由所属账号访问和发送，项目创建者有只读例外（2026-10-08 用户新拍板）；只有开这个对话的人能把它在共有和私有之间切换。停任务：每个人只能停自己发起的那一轮，项目创建者能停任何人的任务。项目创建者能查看所有成员的私有对话，只能看、不能在里面发消息；共有对话切成私有后，别的成员立刻看不到它（项目创建者只读例外），他们在这个对话里还在跑的任务立刻中止、已落地的修改保留；多人同时发言时排队，一轮一轮跑，界面显示排在第几（2026-10-08 用户定），见 `../../plan/account-binding-contract.md`。
- 一键配特效：对一段素材自动配好字幕和动效卡。它是入门时的测试和展示功能，不属于核心功能。接入方式选「云端」时置灰，悬停写明原因。〔用户 2026-10-07 定〕
- 对话是空的时候，对话区里只有一条示例句：「为我快速创建一个视频告诉我软件都可以做什么。」点它就填进输入框。本机与云端相同。〔用户 2026-10-07 定〕
- 云端因节点条件做不了的工具，Agent 会直接说明，不找替代办法；要操作发起人自己界面的工具（选区、播放头、播放与暂停这类），发起方不在线时回「发起方不在线」，Agent 据此继续；发出后可以离开（见下文「云端对话」）。〔用户 2026-10-07 定〕

## Agent 执行

Agent 读项目、看画面、改项目。改卡片代码、新建卡片、新建或改写效果、自定义测量，按当前对话的创造力等级开放。

- **读**：项目全貌、素材清单、当前选中、卡片清单与参数、部件库、序列、剪辑版本、布局与实体框。
- **看**：按时刻渲染整屏或单卡；按镜头拼图看素材；整段动效的 8 帧动图。
- **改时间轴**：加、改、删、复制、切分片段；序列的增删、改名、隐藏、静音、锁定、排序；片段跨序列移动；总时长。
- **改卡**：参数；位置（坐标、矩形、对齐、微调）；不透明度、淡入淡出；强调（阴影、描边）；三维透视；跟随运动轨迹；组合卡的部件增删改移；卡片本身的代码（JS、CSS、HTML），可读取后局部修改，不限于已暴露的参数。
- **建卡**：读建卡规则、新建卡片、看渲染出的 DOM 并对应到源码行。
- **效果**：转场（交叉溶解、淡入、淡出；在时间轴上显示，并把相关片段绑成一组，但不属于时间轴）；滤镜库（整帧调色）、像素映射（逐像素选区）、音频效果库。库类效果定义一次即可挂到多段，改定义时挂着它的各段一起变；为某一段单独建一个也可以。
- **音频**：音量；测量（响度测量是内置的默认方法，Agent 也可以用 JS 自定义测量方法）；音画分离；配音；音频效果（见「效果」）。
- **字幕**：一张字幕卡装整段，整份灌入，单条增删改。

## 云端对话

接入方式选「云端」时的 AI 栏（在线浏览器模式里它就是全部）：

- 对话页签下常驻一行小字「在云端运行，关闭后继续；重新打开可接着看」。发出消息后关页面、退出软件都不拦、不弹确认。
- 连接状态点的悬停说明是「已连接云端 / 正在连接云端… / 连接中断，重新连接中… / 未连接云端」；事件流断了时顶上出一条提示：「和云端 Agent 的连接断了，正在重新连接。云端的这一轮仍在继续，连上后会把错过的过程补齐。」
- 云端 Agent 在跑时继续输入，Enter 是「加入队列」，这一轮结束后自动发下一条（与本机 AI 栏的输入队列、「插入」「编辑」「继续」相同）。
- 改动引出的预渲染在对话里显示一行状态：已把 N 个片段交给云端渲染 / 云端渲染中：x/y / 云端渲染完成 / 云端渲染失败：原因 / 云端渲染暂不可用，画面会在渲染节点恢复后补上。
- 历史列表多一组「云端」：当前账号在本项目有权查看的云端对话：共有对话、自己的私有对话，项目创建者还可只读查看其他成员的私有对话（2026-10-08 用户定；取代原先只列这位成员自己的对话），状态写「进行中 / 已中断 / 出错 / 已失效」；空时写「这个项目里还没有云端对话」。云端对话这一版没有删除与重命名入口。在线页面只有这一组。
- 「AI 设置」置灰（悬停：云端 Agent 的模型由托管方配置）；运行选项里创造力可选，「深度自主」置灰并写原因（附件可用，与本机相同）。
- 桌面版在项目放云端、本机模式下，云端有对话在跑时，AI 栏顶上提示「云端有一个对话正在进行」，点「接上看看」接上；不自动切到云端。没有可用的本机驱动时，空状态里多一个「改用云端 Agent」按钮。
- 创建者关了「云端 Agent」开关时，AI 栏顶上写「项目创建者已关闭云端 Agent。」，不能发消息。
