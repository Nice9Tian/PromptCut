# 前期准备：素材

展开 `../user-workflow.md` 主线的第 1 步。从属于 `user-workflow.md`，与它冲突时以它为准。

用户把素材放进项目，或让 Agent 去找。

## 放进项目

- 用户导入本地视频、图片、音频。
- 用户导入 `.srt` / `.vtt` 字幕稿，挂到某条素材上。
- Agent 从网页链接抓取视频，包括站内搜索、探测清晰度、使用站点登录态。
- Agent 从网页找到图片直链后导入。
- Agent 把用户在对话里发来的附件导入素材库。
- 配音：把文字合成为语音放进素材库，可同时放到时间轴。
- 从视频派生「只有声音」的素材。

## 缺失素材（2026-10-08 用户定，待实施）

- 打开项目确认素材缺失时，弹窗列明找不到的素材；超时、未授权或解码失败不能不加区分地报告成文件不存在。
- 对应视觉内容换成默认文字卡“找不到素材xxx”占位，xxx 为原素材名或可辨认标识。缺失音频用一段提前做好、随软件分发的人声占位，说的是“找不到素材”（2026-10-08 用户更正；原先写的“丢失素材”、合成后存进项目并经素材服务入库，作废）。这段声音每份软件里都有，不存进项目，也不经素材服务入库；项目里记的仍是原素材的引用和“已缺失”的状态。
- 保留原素材标识、引用、片段位置与参数和找回关系，不把占位算作原素材恢复。占位长度怎样适配原片段、视频画面与音轨均缺失时怎样组合尚待落清，不能偷偷改变原时间轴。
- 保存、重开、另一设备读取和导出都要验证占位；原素材找到后保留可替换回原素材的路径。占位人声不随 `.proc`、`.procp` 走，打开文件的那份软件用自己带的那一段。文件是 `src/audio/assets/missing-material.wav`（Windows 系统语音合成，做法见 `../../plan/account-binding-contract.md`「缺失素材占位」）。

## 理解素材

语音转写、镜头切分、主体位置、点的运动轨迹。

- 人和 Agent 共用同一份结果。
- 结果存在素材上，重复使用不重跑。

## 拓展功能

听写、镜头识别、运动追踪、主体检测、素材收集、配音由拓展提供。拓展装没装只影响对应能力能不能用、能用到哪一档，不影响主线。
