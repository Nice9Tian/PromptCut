# 项目：开始与交付

展开 `../user-workflow.md` 主线的第 0 步「开始」和第 5 步「交付」，以及项目级的设置。从属于 `user-workflow.md`，与它冲突时以它为准。

## 开始

- 开始页：新建空项目；打开本地草稿；打开 `.proc`（项目）或 `.procp`（项目 + 素材打包）；加入别人的项目。
- 项目只有一种新建入口。要和别人一起做，在项目设置里勾「多用户协作」；加入别人的项目在开始页。见下文「多用户协作」。
- 开始页显示拓展功能的状态并可就地安装。拓展提供的能力见 `materials.md`。
- 草稿自动保存在本机，开始页可列出、打开、删除。
- 开始页有「存储」〔裁：入口位置，2026-09-29 PC 主会话按用户定的「给清理缓存入口、导出产物有列表大小与删除」落实〕：显示本机的预渲染缓存与导出产物各占多少，以及缓存上限（可改）；「清理缓存」；导出产物按每次导出列出（所属项目、时间、大小），可打开所在目录、删除，也可只删中间文件、留下成片与透明层。标题栏菜单另有「存储…」直达这里。在线浏览器没有这一块。
- 打开旧项目时给一次性迁移提示（素材分类变化、已停用的 Python 卡）。
- 在线浏览器的开始页有“新建项目”和“加入别人的项目”；新建前登录网站账号，项目一律放云端并勾上“多用户协作”，创建者为该账号。本地草稿列表、打开 `.proc` 只在桌面版；暂时离线的未提交改动仍需保留（见 `../product/platforms.md`“在线浏览器”）。

## 多用户协作

- 项目设置里有一个勾选「多用户协作」，新建时和之后任何时候都可以勾上或取消。
- 勾上并保存：本机项目交给本地文档服务托管，同时向云端托管服务登记（离线时稍后自动补）。等待完成后显示邀请链接与二维码（里面是邀请码），并提醒「你的电脑关机后其他人打不开，可在设置里搬到云端」。
  - 本机不能从公网直连时，另提示「局域网外的成员将经中继加入，会受限速」；离线时提示「当前离线，局域网外成员暂时无法加入」。项目照建，不锁任何选项。
- 勾上时的默认：放本机、自由进入、创建者用户名取设备名、密码自动生成并存在本机。这些都可以在项目设置里改，改法沿用创建者的三项特权。
- 取消并保存：等所有内容拉回本机，之后云端托管服务注销登记，其他成员不再能进。项目已在云端的，取消前先把内容全部拉回本机。
- 项目设置里另有「搬到云端」「搬回本机」。
- 保存 `.proc`、`.procp` 和草稿保留非秘密的房间关联；各设备持久保存自己的恢复凭证，普通项目文件不含认证秘密。原设备凭有效凭证重开后自动恢复原身份；凭证丢失、失效或新设备打开时明确要求认证，不仅凭文件内的用户名或角色授权。〔裁：用户授权 `collaboration-reopen-recovery-plan.md` 第 10 节〕
- 原主机在原设备重开后恢复原房间并重新登记上线，地址变化及暂时网络失败自动处理；成员先打开时保留身份等待，主机上线后自动重试。创建者第二设备只恢复创建者连接；云端项目仍存在时恢复云端身份，不自动搬回本机。只有可信云端文档服务确认准确原项目已不存在，才走下文“过期云端项目转本地”。
- 正常重入以服务端最新内容和连续版本为准，不把文件快照自动覆盖共享项目。取消或删除是持久的显式操作，旧文件与后台重试不得撤销；恢复数据缺失或损坏须保留本地内容并明确提示。〔裁：同上〕
- 加入别人的项目在开始页，桌面版和在线浏览器一样。本地项目表单仍为项目名、项目密码、自己的用户名；限定进入填名单里的用户名和密码。云端项目填账号名和密码，由服务器核对；网站已登录仍需在编辑器输入一次，同设备以后可用可撤销的恢复凭证重开，设备不保存密码。
- 云端新建或“搬到云端”前需登录账号，创建者、成员和禁入由云端文档服务记录。云端“任何知道链接的人都可加入”默认勾选，知道链接仍需账号；取消勾选只允许账号名单，被踢账号从任何设备均不能进入。本地自报身份和进入方式不变。
- 邀请码是可作废、可限时限量的令牌，不进日志，不携带账号密码。本地项目仍等价于填对项目名和项目密码，限定进入仍需名单身份；云端只帮助定位项目，不跳过账号认证或禁入。手动表单保留。
- 创建者可以随时作废邀请码并重新生成，不必改项目密码；改项目密码也不影响已有的邀请码。作废后旧链接和旧二维码立刻失效，界面显示新的。
- 创建者特权只有三项：改进入设置、名单或邀请码，删项目，踢人；本地凭创建者用户名和密码，云端凭创建者账号。云端踢人对账号及其所有设备生效；其余操作所有成员一样。
- 自由进入下用户名可以重名，重名的人显示时自动带「(设备名)」。
- Agent 用所属用户的身份，显示为「用户名 · Agent · 第几个对话」，界面用标签区分真人和 Agent。

## 过期云端项目转本地（2026-10-08 用户定）

- 只在可信云端文档服务明确确认准确原项目已不存在或已清理时触发。文件较旧、凭证失效、超时、服务器故障或连错节点都不叫过期。
- 用文件保存的那份内容建立独立本地项目，默认关闭“多用户协作”；需要协作时由用户手动打开。提示一次原云端项目已不在、现在是本地项目；各设备得到的独立副本互不再同步。
- 原云端保存之后的修改不会凭空回到旧文件；缺素材按 `materials.md` 的占位规则处理。文件里没有可用内容时报错并保留原文件，不用空项目覆盖，**需要复核各种不同细节情形**。
- 新保存更新项目状态为本地，重开继续本地设置，不再连旧云端。成功保存前保留原输入；要再放云端，登录后显式“搬到云端”。
- 独立时创建共同标记、将来从标记点合入及可视化冲突处理列为以后任务，本期不实现；不得混同下文的暂时离线重入。

## 暂时离线项目与保存（2026-10-08 用户定）

- 连接暂时失败时保留原云端关联和已知基准，允许的离线改动持久保留。未登录、旧凭证或被踢需要相应认证/拒绝处理，离线内容不授予云端写权限。
- 保存时记录非本机内容确定快照的哈希、时间和版本；本机暂时禁用前台编辑，等待本机写入完成再保存。远端固定快照后仍可继续产生后续版本；无法取得远端确认时明确标为暂时离线，不假称已同步。
- 下次打开或重连，检查是否落后并询问是否发送离线改动。可能覆盖云端期间改动时，显示基准、离线和云端差异的可视化冲突窗口；用户决定后提交，取消保留离线内容，云端又变化时重新核对。
- 保存、重开、进程退出和提交失败都不能丢掉离线改动，也不能把暂时离线文件改成已过期的本地独立项目。

## 交付

- 导出视频：成片，以及只含卡片的透明层；可取消；可打开产物目录。导出完成后产物目录里只留成片与透明层〔裁：逐帧图片等中间文件不再保留，2026-09-29 PC 主会话，见 `../product/platforms.md`「导出产物」〕；历次导出在开始页「存储」里列出、可删除。
- 保存项目 `.proc`；打包保存 `.procp`（连素材一起，换机器直接打开）。
- 只读查看链接：能看不能改。
