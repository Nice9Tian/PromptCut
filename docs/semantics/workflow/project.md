# 项目：开始与交付

展开 `../user-workflow.md` 主线的第 0 步「开始」和第 5 步「交付」，以及项目级的设置。从属于 `user-workflow.md`，与它冲突时以它为准。

## 开始

- 开始页：新建空项目；打开本地草稿；打开 `.proc`（项目）或 `.procp`（项目 + 素材打包）；加入别人的项目。
- 项目只有一种新建入口。要和别人一起做，在项目设置里勾「多用户协作」；加入别人的项目在开始页。见下文「多用户协作」。
- 开始页显示拓展功能的状态并可就地安装。拓展提供的能力见 `materials.md`。
- 草稿自动保存在本机，开始页可列出、打开、删除。
- 开始页有「存储」〔裁：入口位置，2026-09-29 PC 主会话按用户定的「给清理缓存入口、导出产物有列表大小与删除」落实〕：显示本机的预渲染缓存与导出产物各占多少，以及缓存上限（可改）；「清理缓存」；导出产物按每次导出列出（所属项目、时间、大小），可打开所在目录、删除，也可只删中间文件、留下成片与透明层。标题栏菜单另有「存储…」直达这里。在线浏览器模式没有这一块。
- 打开旧项目时给一次性迁移提示（素材分类变化、已停用的 Python 卡）。
- 在线浏览器模式的开始页只有「加入别人的项目」；新建空项目、本地草稿、打开 `.proc` 只在桌面版（见 `../product/platforms.md`「在线浏览器模式」）。

## 多用户协作

- 项目设置里有一个勾选「多用户协作」，新建时和之后任何时候都可以勾上或取消。
- 勾上并保存：本机项目交给本地文档服务托管，同时向云端托管服务登记（离线时稍后自动补）。等待完成后显示邀请链接与二维码（里面是邀请码），并提醒「你的电脑关机后其他人打不开，可在设置里搬到云端」。
  - 本机不能从公网直连时，另提示「局域网外的成员将经中继加入，会受限速」；离线时提示「当前离线，局域网外成员暂时无法加入」。项目照建，不锁任何选项。
- 勾上时的默认：放本机、自由进入、创建者用户名取设备名、密码自动生成并存在本机。这些都可以在项目设置里改，改法沿用创建者的三项特权。
- 取消并保存：等所有内容拉回本机，之后云端托管服务注销登记，其他成员不再能进。项目已在云端的，取消前先把内容全部拉回本机。
- 项目设置里另有「搬到云端」「搬回本机」。
- 保存 `.proc`、`.procp` 和草稿保留非秘密的房间关联；各设备持久保存自己的恢复凭证，普通项目文件不含认证秘密。原设备凭有效凭证重开后自动恢复原身份；凭证丢失、失效或新设备打开时明确要求认证，不仅凭文件内的用户名或角色授权。〔裁：用户授权 `collaboration-reopen-recovery-plan.md` 第 10 节〕
- 原主机在原设备重开后恢复原房间并重新登记上线，地址变化及暂时网络失败自动处理；成员先打开时保留身份等待，主机上线后自动重试。创建者第二设备只恢复创建者连接；云端项目恢复云端身份，不自动搬回本机。〔裁：同上〕
- 正常重入以服务端最新内容和连续版本为准，不把文件快照自动覆盖共享项目。取消或删除是持久的显式操作，旧文件与后台重试不得撤销；恢复数据缺失或损坏须保留本地内容并明确提示。〔裁：同上〕
- 加入别人的项目在开始页，桌面版和在线浏览器模式一样。表单三项：项目名、项目密码、自己的用户名；限定进入时填项目名，以及名单里的用户名和密码。找不到时明确提示。
- 邀请码是一个可作废、可限时限量的令牌，邀请链接和二维码里只带它，不带项目名和项目密码。凭邀请码加入等价于填对了项目名和项目密码：自由进入的项目只需再填自己的用户名；限定进入的项目省去项目名，名单里的用户名和密码照填。手动填表单的路仍然保留。
- 创建者可以随时作废邀请码并重新生成，不必改项目密码；改项目密码也不影响已有的邀请码。作废后旧链接和旧二维码立刻失效，界面显示新的。
- 创建者特权只有四项：改项目密码、名单或邀请码，删项目，踢人，开关托管方在这个项目里的服务（渲染节点、云端 Agent）；其余操作所有成员一样。〔裁：决定 D、G 的直接后果，主会话 2026-10-06，待用户合入前审〕
- 项目放云端时，项目设置里另有一个勾选「云端 Agent」，缺省勾上：在线浏览器模式的成员可以在 AI 栏里用托管方的云端 Agent。项目创建者可以取消，取消后进行中的云端对话立刻停掉，别的成员收到一条气泡「创建者关闭了云端 Agent，进行中的云端对话已被停下」；重新勾上时不提示。其他成员看得到这一项，不能改。放本机的项目没有这一项。〔裁：主会话 2026-10-06，待用户合入前审〕〔用户 2026-10-07 定〕
- 自由进入下用户名可以重名，重名的人显示时自动带「(设备名)」。
- Agent 用所属用户的身份，显示为「用户名 · Agent · 第几个对话」，界面用标签区分真人和 Agent。云端 Agent 显示为「〈用户名〉的云端 Agent」。
- 顶栏的「成员」按钮上写「成员：N 人 · Agent：M 个」：人数只算真人在线的；Agent 个数含本机 Agent 与云端 Agent；托管方的服务（渲染节点）单独一行，不计入任何一个数。成员本人不在线、只有他的云端 Agent 还连着时，他那一行照常显示并标「离线，Agent 在跑」，不计入人数、计入 Agent 个数。〔用户 2026-10-07 定〕

## 交付

- 导出视频：成片，以及只含卡片的透明层；可取消；可打开产物目录。导出完成后产物目录里只留成片与透明层〔裁：逐帧图片等中间文件不再保留，2026-09-29 PC 主会话，见 `../product/platforms.md`「导出产物」〕；历次导出在开始页「存储」里列出、可删除。
- 保存项目 `.proc`；打包保存 `.procp`（连素材一起，换机器直接打开）。
- 只读查看链接：能看不能改。

## 项目设置

名称、画幅比例与方向、帧率、分辨率、主题、创造力等级；多用户协作的开关、放在本机或云端、进入方式与创建者信息；放云端的项目另有托管方服务的开关（渲染节点、云端 Agent）。
