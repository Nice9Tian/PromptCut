# 项目：开始与交付

展开 `../03-user-workflow.md` 主线的第 0 步「开始」和第 5 步「交付」，以及项目级的设置。从属于 03，与它冲突时以 03 为准。

## 开始

- 开始页：新建空项目；打开本地草稿；打开 `.proc`（项目）或 `.procp`（项目 + 素材打包）。
- 开始页显示拓展功能的状态并可就地安装。拓展提供的能力见 `materials.md`。
- 草稿自动保存在本机，开始页可列出、打开、删除。
- 打开旧项目时给一次性迁移提示（素材分类变化、已停用的 Python 卡）。

## 交付

- 导出视频：成片，以及只含卡片的透明层；可取消；可打开产物目录。
- 保存项目 `.proc`；打包保存 `.procp`（连素材一起，换机器直接打开）。
- 只读查看链接：能看不能改。

## 项目设置

名称、画幅比例与方向、帧率、分辨率、主题、创造力等级。
