# 项目：开始与交付

展开 `../user-workflow.md` 主线的第 0 步「开始」和第 5 步「交付」，以及项目级的设置。从属于 `user-workflow.md`，与它冲突时以它为准。

## 开始

- 开始页：新建空项目；打开本地草稿；打开 `.proc`（项目）或 `.procp`（项目 + 素材打包）；加入别人的项目。
- 项目只有一种新建入口。要和别人一起做，在项目设置里勾「多用户协作」；加入别人的项目在开始页。见下文「多用户协作」。
- 开始页显示拓展功能的状态并可就地安装。拓展提供的能力见 `materials.md`。
- 草稿自动保存在本机，开始页可列出、打开、删除。
- 打开旧项目时给一次性迁移提示（素材分类变化、已停用的 Python 卡）。

## 多用户协作

- 项目设置里有一个勾选「多用户协作」，新建时和之后任何时候都可以勾上或取消。
- 勾上并保存：本机项目交给本地文档服务托管，同时向云端托管服务登记（离线时稍后自动补）。等待完成后显示邀请链接与二维码（里面是邀请码），并提醒「你的电脑关机后其他人打不开，可在设置里搬到云端」。
  - 本机不能从公网直连时，另提示「局域网外的成员将经中继加入，会受限速」；离线时提示「当前离线，局域网外成员暂时无法加入」。项目照建，不锁任何选项。
- 勾上时的默认：放本机、自由进入、创建者用户名取设备名、密码自动生成并存在本机。这些都可以在项目设置里改，改法沿用创建者的三项特权。
- 取消并保存：等所有内容拉回本机，之后云端托管服务注销登记，其他成员不再能进。项目已在云端的，取消前先把内容全部拉回本机。
- 项目设置里另有「搬到云端」「搬回本机」。
- 加入别人的项目在开始页，桌面版和在线浏览器模式一样。表单三项：项目名、项目密码、自己的用户名；限定进入时填项目名，以及名单里的用户名和密码。找不到时明确提示。
- 邀请码是一个可作废、可限时限量的令牌，邀请链接和二维码里只带它，不带项目名和项目密码。凭邀请码加入等价于填对了项目名和项目密码：自由进入的项目只需再填自己的用户名；限定进入的项目省去项目名，名单里的用户名和密码照填。手动填表单的路仍然保留。
- 创建者可以随时作废邀请码并重新生成，不必改项目密码；改项目密码也不影响已有的邀请码。作废后旧链接和旧二维码立刻失效，界面显示新的。
- 创建者特权只有三项：改项目密码、名单或邀请码，删项目，踢人；其余操作所有成员一样。
- 自由进入下用户名可以重名，重名的人显示时自动带「(设备名)」。
- Agent 用所属用户的身份，显示为「用户名 · Agent · 第几个对话」，界面用标签区分真人和 Agent。

## 交付

- 导出视频：成片，以及只含卡片的透明层；可取消；可打开产物目录。
- 保存项目 `.proc`；打包保存 `.procp`（连素材一起，换机器直接打开）。
- 只读查看链接：能看不能改。

## 项目设置

名称、画幅比例与方向、帧率、分辨率、主题、创造力等级；多用户协作的开关、放在本机或云端、进入方式与创建者信息。
