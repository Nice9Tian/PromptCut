# 产品目的

## 定位

PromptCut 是一个 AI 视频剪辑工作台。它让用户能够用自然语言指挥 Agent 完成视频剪辑，也支持用户自己动手剪辑。两者可以并行，构成人与 Agent 协作剪辑的工作方式。

## 目标用户

不限定用户群体和剪辑熟练度。

## 现状问题

现有视频剪辑软件在以下方面不能满足需要：

1. 对 Agent 不友好：Agent 难以操作现有软件完成剪辑。
2. 专业软件门槛高：操作复杂，计算负担重。
3. 轻量软件自由度低。
4. 不适合多人在线协作。

## 核心目的

**用户可以通过自然语言指挥 Agent 完成剪辑。** 这是本项目唯一的核心目的，所有设计决策以它为最高优先级。

## 人与 Agent 的分工

以人指挥 Agent 为主要工作方式。同时保留用户手动操作的能力，包括直接剪辑和调整参数，供用户在需要时介入或修正。两种方式可以并行，共同构成人与 Agent 协作剪辑。

## 愿景

多人、多设备在同一项目中协作。该愿景与核心目的正交：两者互不依赖，任一方的实现程度不约束另一方。

## 成功标准

一般用户仅通过语言描述，即可达到常见熟练者的剪辑水平。该标准是方向性的，暂不给出量化指标。

## 范围

一期只面向桌面浏览器和桌面应用。其它平台不在一期范围内，但一期的设计须保留向其它平台扩展的能力。
