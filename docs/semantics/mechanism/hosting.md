# 云端登记与协作重开恢复

从属于 `../product/hosting.md` 与 `../product/document-service.md`。本次契约落实用户授权的 `../../plan/collaboration-reopen-recovery-plan.md` 第 10 节；现阶段能力边界和未交付事项在执行报告中逐项记录，不能视作其它产品承诺已实现。

## 文件与设备记录

`.proc` 顶层可选 `collaboration` 版本 1，字段为 `roomId`、`service`、`where`（lan/hosted）与非秘密 `hint`。`.procp` 与草稿复用序列化。内容 ID 不等于房间 ID。拒绝无效类型、超长关联与含用户信息、查询串、片段的服务 URL；未知版本保留原关联，显示不支持恢复，不访问设备秘密。

身份按规范化服务身份、房间、本机配置、member/creator 与用户名保存，内容 ID 绑定所选身份。Windows 使用当前用户 DPAPI；其它系统使用独立私有设备密钥和 AES-GCM。派生 K 视同密码能力；主机登记密钥与设备绑定只在本机保护存储中，浏览器不接收登记密钥。文件地址必须与已信任的设备记录精确匹配；明确认证前不向未知服务发送缓存凭证，认证请求拒绝重定向。

托管端换机后，换下来的托管主机名按对照表（`server/auth/hosted-default.mjs` 的 `RETIRED_HOSTED_HOSTS`）换成现用主机名：读项目文件的关联、设备保护存储、浏览器本机记录与渲染节点共享配置时都先换，协议、端口、路径不变，再按上一段精确匹配；存回时写的是新地址，已保存的身份不用重新认证。2026-10-06 起阿里云 `8.219.80.16`（含 `8-219-80-16.sslip.io` 及舞台子域）换成新云节点。〔裁：用户 2026-10-06 定，阿里云到期不续、数据整体拷到新节点，旧项目打开后自动切到新节点〕

稳定目录为 `PROMPTCUT_DATA_DIR` 下的 `collaboration/`，文档状态为同目录 `docservice/`，保留显式 `PROMPTCUT_DOCSERVICE_DATA` 测试覆盖。加密记录经临时文件、刷盘、原子替换写入，保留上一版 `.bak`；损坏失败关闭，不能用空记录覆盖。旧浏览器记录仅在精确匹配服务与房间后迁移；成功写入保护存储后才替换旧记录。自动生成密码的查看信息也迁到保护存储。

同一稳定目录的 `device.json` 首次保存设备 ID，以后不随网卡枚举、端口或运行副本变化重新生成；显式测试设备覆盖不写入该文件。旧运行目录的 `out/docservice/` 仅在稳定文档目录不存在时，先完整复制到临时目录，再原子登记；原目录保留，已有稳定目录不覆盖，外部链接拒绝自动迁移。旧文档数据没有本机原主机绑定时，不因创建者凭证而自动接管。

保护存储更新持有独占进程锁并重新读取磁盘最新记录，多运行实例合并身份及注销变化。只有锁主进程已退出才回收锁；无法确认或锁损坏则保留记录并报错，不结束其它进程。首次加载旧身份及离线日志完成前不写新日志；恢复空项目期间禁止演示卡和自动时长改动污染旧操作。

非 Windows 的私有设备密钥经临时文件刷盘后独占发布；并发首次启动只复用胜出的密钥，不覆盖它。回首页清除共享显示、恢复入口及 URL 中的 editor/open/draft/join 启动参数，刷新保持首页；迟到恢复结果不能重新挂接旧房间。〔裁〕执行报告卡点 5（`../../reports/REPORT-collaboration-reopen-recovery.md`）

## 登记、认证与租约

主机出站 `POST /hosting/register`，登记密钥放 Authorization；同一房间固定原主机设备。登记只保存专用校验派生值 `SHA256(domain, roomId, K)`，无法通过主机原 K 认证；名字、盐、名单、禁入与代数随登记更新。在线租约 30 秒、续约 10 秒，在线同时要求有效租约和出站隧道。不同设备拒绝；不同活动实例拒绝；原设备旧隧道已断后允许新实例恢复。异常退出由租约失效回收，云端重启后必须重新登记。

成员用 `/hosting/challenge` 和 `/hosting/resolve`，证明绑定房间、用户名、设备、身份与一次性随机挑战。错误认证与禁入明确拒绝，主机离线返回可重试状态。临时路由能力最长 15 分钟，只用于找到并访问该房间；主机再独立挑战认证。票据仍由主机签发，网关只保存票据摘要和所属房间、用户、设备、代数及有效期，不签发会话票据。

恢复重试从 500 毫秒指数增长至 30 秒，遵守 Retry-After。认证、删除、禁入、主机冲突与存储损坏停止盲目重试。页面任务代数阻止过时回调、主机恢复和登记。取消或删除先原子保存本机墓碑与待云端注销记录，注销成功后移除待办；云端不可达时待办跨重启保留，服务启动及每 30 秒重试。旧文件不能绕过墓碑。磁盘写失败必须阻止宣称恢复记录已可靠保存。

本机保护存储仅将有明确证据的 OS/保护进程暂时错误（超时、占用、资源暂缺）及确认仍存活的写锁视为可重试，界面显示等待本机存储并沿用同一退避。解密、摘要、格式与无法确认的锁错误仍失败关闭。诊断只返回固定阶段、固定错误类别与耗时，不返回原异常、路径、项目或保护字节。〔裁〕执行报告卡点 6 第 2 行（`../../reports/REPORT-collaboration-reopen-recovery.md`）

## 出站流式中继

原主机连接 `/hosting/tunnel/<roomId>`，目标固定为本机回环文档及素材服务。成员连接 `/hosting/relay/<roomId>/doc` 或 `asset`；HTTP 路径白名单禁止本机管理接口。转发的真实远端标记阻止回环信任透传。所有素材字节流式传送，不保存整文件或落盘；单用户与设备的所有通道、双向合计不超过 1 MiB/s，服务总量默认 16 MiB/s、可通过构造参数调整。最多 256 通道，每通道排队最多 4 MiB，隧道写缓存超 4 MiB 则关闭相应通道；通过暂停/恢复与流背压约束内存。

素材及 Agent、卡片和渲染节点票据取得后，在当前已认证路由上登记其摘要，再将原票据交实际服务。素材查询串只允许只读票据，原服务仍核验权限、到期和代数。重新加入后重取地址与票据，离开共享项目撤销旧绑定。

页面接续中继会话时重新发现路由，在会话项之外携带网关路由能力；网关核验后移除自己的路由项，原文档服务继续严格核验会话秘密，不重新初始化内容或版本。可信发现/挑战明确认证失效、禁入或删除时停止重试，并沿用同一个身份清理流程；暂时网络错误保留会话与离线队列。渲染节点的绑定和撤销按发出顺序完成，旧连接迟到的票据不能作用到重入后的新连接。〔裁〕执行报告卡点 4（`../../reports/REPORT-collaboration-reopen-recovery.md`）

## 服务状态优先与离线记录

所有文件入口及刷新进入统一协调器：解析关联、选设备身份、恢复原主机或发现路由、重新认证、取得已确认状态、挂接同步及素材。正常重入禁止空项目初始化；缺服务状态显示损坏提示。离线日志记录原版本与未确认操作，重入仍用原期望版本；有远端冲突则沿用先备份、用户决定重放或丢弃的流程。保存文件等待操作确认、身份和当前日志可靠写入；普通内容快照不会授予权限或主机资格。

## 显式搬迁与恢复位置

沿用 `../workflow/project.md` 已有的「搬到云端」「搬回本机」，不把文件重新打开或创建者身份当成搬迁授权。房间 ID、账户派生凭证和操作版本连续；一次搬迁以独立事务 ID、源位置代数、精确目标和最终文档/素材摘要登记。源服务参与最终状态采集，可靠保存封锁状态后拒绝已有及新接入的写入、票据和会话接续；没有源状态时不从文件自动接管。无搬迁记录的本机房间仍可离线使用。

目录按 `prepared → ready → committed` 原子切换：准备时撤销旧租约、通道和网关能力；新目标完整校验私有暂存后才确认 ready；只有可信源登记权限能发布位置，目标登记密钥只证明目标准备状态。代数递增并替换登记校验值，旧主机不能重新登记或删除新位置。正常退出只注销租约，显式删除是持久最终状态，在准备或 ready 阶段也不能被迟到发布撤销。原记录和旧目录保留，安装/复制中断同事务补齐，不回滚封锁或发布半完成位置。

服务内部暂存包括整个房间文档目录、已完整入库的三个素材命名空间及账户、禁入和邀请状态，保留旧邀请校验所需的房间私有摘要密钥。当前项目明确引用的素材原尺寸、小尺寸或 CAS 产物缺失时单独报告数量，尚未封锁的源房间保持可编辑；不将缺素材报告成身份失效。文档缓存在目标安装前清除，旧会话关闭；目标未激活时不能接入，激活前再次核对全部文件。完成后重取成员路由和票据，旧代数票据失效。

本机到云端由原设备的本机恢复接口启动，源登记密钥只从设备保护存储读取。目标地址固定为该房间已信任的托管服务，文件地址、页面参数和重定向不能改变它。云端部署组合在自身文档/素材目录接收私有暂存，目录角色只保留摘要和位置；字节走独立 HTTP 流，不经文档会话或页面。目标登记密钥在服务器私有目录中原子保存，只返回校验摘要及设备 ID。目录确认前不对外发布；两端重开后用原事务恢复，目标已提交时自动激活并登记。接口和实际覆盖边界见 `../../plan/collaboration-relocation-contract.md` 及验收报告。

云端到本机由已有有效身份的成员在目标设备显式启动，首次证明绑定实际目标设备；源服务参与封锁、导出和发布，不将成员权限扩大为源主机登记权限。本机在请求前加密落盘原事务、新目标登记密钥和专用传输能力，云端只保存能力摘要。两端重开后凭精确原事务续传；完成后原子写入目标主机绑定和当前位置。持久搬迁任务完成前协调器保持等待，不能因旧源暂时仍可访问而提前加入；完成后设备绑定优先于旧文件位置提示。删除/取消清任务并留下注销待办，迟到完成不复活。〔裁〕执行报告卡点 8 第 2、3 行（`../../reports/REPORT-collaboration-reopen-recovery.md`）

Agent 接续中继会话时重新取得当前页面委托票据；网关先核验权限，再剥除仅供网关的票据项，原文档服务仍严格核验会话秘密。订阅重开在首次取票或握手暂时失败时也沿现有退避继续，不仅在曾经打开后才安排重试；关闭/解除订阅仍撤销它。〔裁〕执行报告卡点 9 第 1、2 行（`../../reports/REPORT-collaboration-reopen-recovery.md`）

# 云端 Agent 服务的部署

从属于 `../product/hosting.md` 的「托管方的 Agent 服务」。本节全部〔裁：主会话 2026-10-06；出处 `../../plan/cloud-agent-contract.md` 第 2.2、8、10、11、20 节〕。

- **进程与目录**：PM2 的 `promptcut-agent`（`server/hosted/deploy/pm2-promptcut-agent.config.cjs`），单进程，`--max-old-space-size=1536`、`max_memory_restart: '2G'`、`kill_timeout: 8000`；只绑回环，只经反向代理对外（`/agent/` 一段见 `server/hosted/deploy/nginx-location-agent.conf`）。代码不单独上传，用 `deploy-render` 放上去的那份检出，Agent 服务、渲染服务、在线页面须出自同一个提交，`/healthz` 的 `codeVersion` 用来核对。数据目录 `PROMPTCUT_AGENT_DATA`（0700），按「项目 / 主人 / 对话」分目录存对话，另有模型配置、Key 密文、`limits.json`、用量流水。
- **服务身份**：凭 `PROMPTCUT_AGENT_SECRETS` 下 `service-key.json`（服务名 `agent` 的私钥，由 keygen 生成）连文档服务的控制连接；不读集群令牌；文档服务一时连不上不退出，自己退避重连，期间新请求回 503。
- **部署子命令**：`keygen-agent`、`deploy-agent`、`status-agent`、`stop-agent`，都收 `--dry-run`。
- **Key 与换机**：Key 的密文由本机指纹派生口令封装，整个文件拷到别的机器解不开，换机后要重新录入；对话与用量数据目录整个拷走即可。迁移办法见 `../../plan/hosting-migration.md`。
