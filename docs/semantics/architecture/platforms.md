# 平台

展开 `../architecture.md` 的「默认位置」和扩展点，以及 `../product-purpose.md` 的范围。从属于 `architecture.md`，与它冲突时以它为准。

## 面向的平台

| 平台 | 运行形态 | 一期 |
|---|---|---|
| 桌面应用 | 本地模式：带预渲染进程 | 做 |
| 桌面浏览器 | 在线浏览器模式 | 做 |
| iPad 浏览器 | 在线浏览器模式，低内存档 | 不做 |
| iPad 应用 | 在线浏览器模式套壳，没有预渲染进程，低内存档 | 不做 |
| 手机浏览器 | 在线浏览器模式，低内存档 | 不做 |
| 手机应用 | 在线浏览器模式套壳 | 不做 |

- 在线浏览器模式的代码是核心，不依赖平台名。将来的平板和手机应用在它外面套壳复用代码。
- 页面代码只按宿主能力分支（有没有预渲染进程、能不能在 Worker 里用 WebGL、是否低内存），不按平台名分支。
- Agent 端（Agent 服务与预渲染进程的 Agent 模式、Full 模式）面向 Windows、Linux、Ubuntu。

## 本地模式

- 桌面应用自带运行所需的全部组件：Node、Chrome、ffmpeg、内置 Python。用户不需要自己安装它们。
- 可以请求本机的预渲染进程。
- 内置 Python 只用于感知类工具（语音转写、镜头识别、运动追踪、主体检测、素材收集），不用于卡片。
- 关闭编辑界面后转入后台运行，见 `../user-workflow.md` 的「后台运行」。

## 在线浏览器模式

- 请求不到预渲染进程。后台舞台在闲时兼做预渲染者，产 HTML 快照，存在页面本地。
- 可以从云端取别人预渲染好的快照，直接用在可见舞台上。
- 没有本机转码能力，也没有轨道流：重卡在播放时每拍换一次快照；换帧成本装不下预算的重卡透明；暂停后照常追到精确活渲。
- 一期只支持内置卡片。含用户卡或图卡的项目，这些片段透明，并在时间轴上提示「该模式暂不支持自定义卡」。

## 预留的接口

- **云端合并分发**：各客户端把自己预渲染出的共享结果上传，云端合并去重后分发给其它客户端。现在只实现上传自己的。
- **在线重型控件渲染服务**：给浏览器模式配专门的在线渲染服务，接口形状与 Agent 模式的查询渲染相同，另加取轨道流分段。现在只留接口。
