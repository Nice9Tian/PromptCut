# 项目数据模型

展开 `../architecture.md`。从属于 `architecture.md`，与它冲突时以它为准。项目文档的真身在文档服务，见 `document-service.md`。本册写产品功能（二级）；剪辑段与剪辑标签怎么做到见 `../mechanism/project-model.md`（2026-10-20 新建）。

## 项目

一个项目包含：名称、画幅宽高、帧率、总时长、主题、三维透视强度、素材库、效果库（滤镜、像素映射、音频效果）、多条剪辑。

- **总时长**：缺省等于内容末尾，跟着内容走；用户可以手动缩短（截断），不能拉长到内容末尾之后。空项目保留原值。

## 剪辑

- 一个项目可以有多条剪辑，每条剪辑是一条独立的时间轴，有自己的序列、转场和总时长。新项目只有一条「剪辑1」，其余由用户或 Agent 新建（2026-10-20 用户定）。已有项目里的剪辑原样保留，不因此删减。
- 同一时刻只有一条剪辑处于激活状态。编辑界面、预览、导出只作用于激活的那条。Agent 工具里按片段 id 修改片段属性的那几个（改参数、时段、框、强调、音量静音），片段在别的剪辑里时就地修改那条剪辑，不切换激活的剪辑——激活的剪辑是所有成员共享的，切换会让每个人的界面一起翻（2026-10-21 用户定）。
- Agent 看画面时可以指定看哪条剪辑，不指定就是激活的那条；看别的剪辑不切换激活的剪辑、不改项目、不动任何人的界面（2026-10-21 用户定）。
- 剪辑可以放进另一条剪辑的序列里，成为一个**剪辑段**（2026-10-20 用户定）。剪辑段引用那条剪辑而不是复制：被引用的剪辑改了，引用它的各处画面与声音一起变。一条剪辑不能直接或间接引用自己，任意深度都算（〔裁：Argon 审 2026-10-20〕补「任意深度」）。
- 协作中各自的改动合起来造成的循环引用，或引用了已经删掉的剪辑，那一段不画、不出声，别的内容照常显示，不报错、不白屏（〔裁：Argon 审 2026-10-20〕）。
- 删除一条被别的剪辑引用的剪辑时，先说明它被哪些剪辑用着；确认后连同引用它的剪辑段一起删，可撤销。Agent 删除同样要明示确认。最后一条剪辑不能删（〔裁：Argon 审 2026-10-20〕补这半句，原代码已如此）。
- **剪辑分两类**（2026-10-24 用户定）：**2D 剪辑**的画面在平面上合成，**3D 剪辑**的画面在空间里合成。类型是剪辑自己的属性，用户看得见、改得动，不由系统按内容猜。新建的剪辑都是 2D 剪辑，已有项目里的剪辑都是 2D 剪辑，行为一个字不变。两类剪辑都能作为剪辑段放进另一条剪辑：放进去的那条按自己的类型合成出整帧，外层照剪辑段的规矩用这一帧。

## 序列

- 序列不分种类：卡片段、素材段和剪辑段都能放在同一条序列上（〔裁：Argon 审 2026-10-20〕随「剪辑段」同步改）。
- 同一条序列内片段不重叠。
- **2D 剪辑里，时间轴上靠上的序列画在上层。**
- **3D 剪辑里，谁盖住谁按深度，不按序列**（2026-10-24 用户定）。序列在 3D 剪辑里只管三件事：把片段分组、排时间、以及同深度时谁在前。用户看得到这个区别，所以剪辑的类型要在界面上写明。

## 片段

- 每个片段有起止时间（秒）。
- **卡片段**：用哪张卡、参数、在画面上的框（位置、尺寸、锚点、缩放、旋转，可选三维）、淡入淡出、不透明度、强调（阴影、描边），可绑定一条运动轨迹跟随画面目标。组合卡的片段另带部件实例树。
- **素材段**：用哪段素材、从素材的哪一秒开始，以及和卡片段相同的框、淡入淡出、不透明度；音频段的不透明度即音量。素材段可挂滤镜、像素映射、音频效果。
- **视频段的速度**（2026-10-23 用户定）：视频段另有播放速度，缺省 1 倍，可设 0.25～4 倍，下拉常用档之外还能手动输入（套了素材效果卡的视频段同样可设）。改速度保住入点（起点和从素材第几秒开始不变）、用到的那截素材不变，时长按新速度重算。
  - **相邻段怎么让位**：变长会和同一条序列上后面的段重合时，把后面的段整体往后推，推到放得下为止；变短时尾部留空，后面的段不动。推不开时（后面的段在锁着的序列上、或推过去仍然重叠）整个不改并说明原因 —— 没有任何截断路径。
  - **挂着转场的段也能改速度**：转场跟着调整，装不下时转场缩短并弹气泡说明；连最短的转场都装不下才拒绝。
  - **声音**：变速的视频段不出原声（挂在它上面的音频效果同样不出）；**声画一体卡例外：它挂在变速段上照常出声**（2026-10-23 用户定「出声。」，推翻同日早先的〔裁〕V21-28）——卡从这段素材读进去的声音随倍率变速变调，卡自己合成的那部分按卡自己的时钟走、音高不变；可以音画分离，分出来的声音段随倍率变调（2 倍高八度、0.5 倍低八度），第一版不做保调变速。变速的视频段可以当音频素材效果卡的声音输入（卡挂在这一段上，或别处的卡接这一段的素材都行），卡拿到的声音同样随倍率变速变调（2026-10-23 用户定「放开。」）。语音转文字转的是原素材 1 倍的声音，铺字幕时按速度把时间戳换到时间轴。
  - 切分时后半段的素材起点按速度推进。预览、导出、Agent 看画面按同一个速度取帧。Agent 暂时没有改速度的工具（2026-10-23 用户定「暂时不用」）。〔裁：clip-speed 2026-10-23；超出 0.25～4 时拒绝并提示而不夹到边界〕
- **剪辑段**：引用哪条剪辑、从被引用剪辑的哪一秒开始，以及和素材段相同的框、淡入淡出、不透明度与音量（2026-10-20 用户定）。剪辑段放好以后引用哪条剪辑不能改，编辑界面和 Agent 都不能换；要换就删掉这段重新放一段（2026-10-21 用户定）。画面是被引用剪辑在对应时刻的整帧合成，声音是它的混音。剪辑段可以独立静音、参与转场、切分（后半段从被引用剪辑的相应位置接着开始）和复制；不挂滤镜、像素映射、音频效果（〔裁：Argon 审 2026-10-20〕补静音、转场、切分复制，并写明不挂效果）。新建或拉长剪辑段时，不能超出被引用剪辑当时的总时长；被引用剪辑事后变短，已有剪辑段在父剪辑上的起止不变，超出被引用剪辑总时长的部分画面透明、无声（〔裁：Argon 审 2026-10-20〕，原句「剪辑段不能超出被引用剪辑的总时长」与「被引用剪辑改了跟着变」冲突）。

## 素材

- 素材分视频、音频、图片三类，按文件内容的哈希寻址：换文件名、换机器都是同一份素材。
- 同一份素材可以有两档：素材原尺寸和素材小尺寸，见 `asset-service.md`。
- 素材理解的结果（转写、镜头切分、主体位置）挂在素材上，人和 Agent 共用。
- 可以从视频派生一份「只有声音」的素材，和源视频共用同一个文件。

## 效果库

- 滤镜、像素映射、音频效果都存在项目的效果库里，定义一次即可挂到多个片段；改定义时挂着它的各段一起变。
- **滤镜**负责整帧调色；**像素映射**只负责需要逐像素判断的选区（抠色、按位置或时间的选区、换成另一段素材），整帧调色一律用滤镜。

## 转场

- 转场是独立的对象，有三种：交叉溶解、淡入、淡出。它在时间轴上显示，但不属于任何序列。
- 转场把它引用的片段绑成一组：组内相对时间关系锁住，不能单独改时长、换序列、切分；整组平移允许。删掉转场后这些片段恢复自由。

## 字幕

- 一段口播的字幕装在一张字幕卡里，不是每句一个片段。
- 字幕逐条可编辑，同一时刻不会有两条字幕重叠。

## 卡片音频引用与静音

- 有声动效卡的音频产物是可持久化的素材引用，归原视觉片段所有；它不把视觉片段变成素材段，也不额外创建一条会重复播放的声音片段。
- 片段独立静音与序列静音分开保存。复制、切分、撤销、重做和项目重开保留片段静音状态；恢复片段声音不解除序列静音。
