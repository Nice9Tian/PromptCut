# 手机版 UI 演示稿

纯静态 HTML，假数据，不引用 `src/`、`server/`，不调接口，不引外部资源。运行时和构建都不读本目录。

打开：直接双击 `index.html`（桌面浏览器里是 375×780 的手机壳；真手机或窄窗口下占满屏）。

界面：项目列表、编辑主界面（预览 + 剪辑标签 + 时间轴）、素材库、卡片库、参数调整、Agent 对话、冲突合并、成员、导出。

## 第二轮：时间轴改成「默认单轨 + 编辑态展开」

- 默认编辑界面：下面只有一条主轨，只放主要内容；各段一样宽（不按真实时长缩放），段上标时长，右上写「共 00:24」；段间的 ◇ 是转场，＋ 是还没有转场。点一段进入编辑，长按拖动换顺序。其它内容（文字、字幕、卡片、音乐）列在主轨下面，点一下进入编辑。
- 编辑状态：点主轨的一段、转场、叠加内容，或点预览里的文字，就展开完整时间轴（按时间缩放、刻度、四轨、播放头、两端手柄），顶部「✕ 退出 / ✓ 完成」（✕ 放弃本次编辑，✓ 保留），底部是这一项的工具（分割、复制、样式、动画、不透明度、静音、删除……）。退出后回到单轨。
- 点通示例：打开「夏日海边 Vlog」→ 点「叠加内容」里的「T 夏日海边」→ 点工具栏「样式」改字号 → 点 ✓；或点底部「文字」新建文字，直接进入编辑。
- 「主要内容」怎么挑选的待办在 `index.html` 的 `mainClips()` 里。
- `ref/` 是用户给的美图秀秀参考截图，只作交互参考。
