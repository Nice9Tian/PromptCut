# 手机版 UI 演示稿

纯静态 HTML，假数据，不引用 `src/`、`server/`，不调接口，不引外部资源。运行时和构建都不读本目录。

打开：直接双击 `index.html`（桌面浏览器里是 375×780 的手机壳；真手机或窄窗口下占满屏）。

界面：项目列表、编辑主界面（预览 + 剪辑标签 + 时间轴）、素材库、卡片库、参数调整、Agent 对话、冲突合并、成员、导出。

## 第二轮（已被第三轮取代的部分见下）

- 编辑状态展开完整时间轴、顶部「✕ 退出 / ✓ 完成」、底部是选中那一项的工具：保留。

## 第三轮：默认布局照美图秀秀改

- 默认编辑页：预览在剩余空间里垂直居中；播放条在预览和缩略时间轴之间；缩略时间轴贴着底部工具栏；最底下是分页「剪辑 / 时间轴」。去掉了「叠加内容」列表和预览下面的剪辑标签行。
- 点缩略卡不进入编辑（只把预览跳到这一段）；长按拖动换顺序。
- 点分页「剪辑」→ 选一个剪辑（剪辑 1、片头、可新建），缩略时间轴和总时长跟着换。
- 点分页「时间轴」→ 展开完整时间轴；点一段选中后出现这一项的工具；顶部 ✕ / ✓ 退回默认布局。叠加内容（文字、字幕、卡片、音乐）从这里编辑。
- 点通示例：项目列表打开「夏日海边 Vlog」→ 点「时间轴」→ 点「T 夏日海边」（再点一下可拖两端）→ 工具栏「样式」改字号 → ✓ 回到默认布局。
- 名词见 `GLOSSARY.md`；「主要内容」怎么挑选的待办在 `index.html` 的 `mainClips()` 里。
- `ref/` 是用户给的美图秀秀参考截图，只作交互参考。

## 第四轮：三个分页 + 当前帧标记 + 手势

- 最底部分页：缩略预览 / 时间轴 / Agent（Agent 现在是一个分页，不再是工具栏按钮）。
- 缩略预览的工具栏：视频、图片、音频、剪辑、卡片、文字（可横向滑动）；视频/图片/音频直接打开素材库对应分类，「剪辑」打开选剪辑面板。
- 缩略时间轴正中有固定的竖线（当前帧标记），卡在下面滚动；播放时自动滚动，按住左右拖动 = 调整当前时间。点卡选中，点外面取消选中；先选中再长按拖动才换顺序。
- 完整时间轴：空白处按住左右拖 = 横向滑动，点空白处取消选中，点/拖刻度尺移动播放头。

## 第五轮：「引用」按钮

- 缩略预览：点选一张缩略卡后，子导航栏最前面出现「引用」，取消选中后消失。
- 完整时间轴：选中片段后，工具里「分割」后面紧跟「引用」。
- 点「引用」切到 Agent 分页，输入框上方带着引用标记，发送后消息上也显示。

## 第六轮：顶栏瘦身

- 顶栏只留返回、项目名、导出（项目名完整显示）。
- 「冲突合并」和成员按钮挪到预览画面右上角（小号、半透明深色底）；时间轴分页预览变小时自动改成紧凑写法（「⚠ 2」「👥 2·2」）。「Agent 正在改」提示排在这两个按钮下面。

## 第六轮补充：底部面板上下滑动

- 素材库每类、卡片库每类假数据都在 15 个以上，内容超过一屏，能上下滑动；分类标签固定不随内容滚走。
- 按住面板顶部横杠或头部往下拖 = 关闭，往上拖 = 展开到接近全屏，松手回弹到最近的一档；所有底部面板都一样。
