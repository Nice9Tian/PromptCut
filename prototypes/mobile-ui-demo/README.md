# 手机版 UI 演示稿

纯静态 HTML，假数据，不引用 `src/`、`server/`，不调接口，不引外部资源。运行时和构建都不读本目录。

打开：直接双击 `index.html`（桌面浏览器里是 375×780 的手机壳；真手机或窄窗口下占满屏）。

界面：项目列表、编辑主界面（预览 + 剪辑标签 + 时间轴）、素材库、卡片库、参数调整、Agent 对话、冲突合并、成员、导出。

## 第二轮（已被第三轮取代的部分见下）

- 编辑状态展开完整时间轴、顶部「✕ 退出 / ✓ 完成」、底部是选中那一项的工具：保留。

## 第三轮：默认布局照美图秀秀改

- 默认编辑页：预览在剩余空间里垂直居中；播放条在预览和缩略时间轴之间；缩略时间轴贴着底部工具栏；最底下是分页「剪辑 / 时间轴」。去掉了「叠加内容」列表和预览下面的剪辑标签行。
- 点缩略卡不进入编辑（只把预览跳到这一段）；长按拖动换顺序。
- 点分页「剪辑」→ 选一个剪辑（剪辑 1、片头、可新建），缩略时间轴和总时长跟着换。
- 点分页「时间轴」→ 展开完整时间轴；点一段选中后出现这一项的工具；顶部 ✕ / ✓ 退回默认布局。叠加内容（文字、字幕、卡片、音乐）从这里编辑。
- 点通示例：项目列表打开「夏日海边 Vlog」→ 点「时间轴」→ 点「T 夏日海边」（再点一下可拖两端）→ 工具栏「样式」改字号 → ✓ 回到默认布局。
- 名词见 `GLOSSARY.md`；「主要内容」怎么挑选的待办在 `index.html` 的 `mainClips()` 里。
- `ref/` 是用户给的美图秀秀参考截图，只作交互参考。

## 第四轮：三个分页 + 当前帧标记 + 手势

- 最底部分页：缩略预览 / 时间轴 / Agent（Agent 现在是一个分页，不再是工具栏按钮）。
- 缩略预览的工具栏：视频、图片、音频、剪辑、卡片、文字（可横向滑动）；视频/图片/音频直接打开素材库对应分类，「剪辑」打开选剪辑面板。
- 缩略时间轴正中有固定的竖线（当前帧标记），卡在下面滚动；播放时自动滚动，按住左右拖动 = 调整当前时间。点卡选中，点外面取消选中；先选中再长按拖动才换顺序。
- 完整时间轴：空白处按住左右拖 = 横向滑动，点空白处取消选中，点/拖刻度尺移动播放头。

## 第五轮：「引用」按钮

- 缩略预览：点选一张缩略卡后，子导航栏最前面出现「引用」，取消选中后消失。
- 完整时间轴：选中片段后，工具里「分割」后面紧跟「引用」。
- 点「引用」切到 Agent 分页，输入框上方带着引用标记，发送后消息上也显示。

## 第六轮：顶栏瘦身

- 顶栏只留返回、项目名、导出（项目名完整显示）。
- 成员按钮在预览画面右上角（小号、半透明深色底；时间轴分页预览变小时改成紧凑写法「👥 2·2」）。「Agent 正在改」提示排在它下面。（第九轮起，冲突合并不再是这里的按钮，见下。）

## 第六轮补充：底部面板上下滑动

- 素材库每类、卡片库每类假数据都在 15 个以上，内容超过一屏，能上下滑动；分类标签固定不随内容滚走。
- 按住面板顶部横杠或头部往下拖 = 关闭，往上拖 = 展开到接近全屏，松手回弹到最近的一档；所有底部面板都一样。

## 第七轮：返回的层级

- Agent / 时间轴分页按左上角「‹」→ 回缩略预览（当前剪辑、当前时间、选中状态保持）；缩略预览里按「‹」→ 回项目列表。
- 浏览器后退（系统返回手势）同一规则：分页 → 缩略预览 → 项目列表。进分页时推一层历史记录，分页之间切换只替换当前这层，所以来回切多次后后退一次仍回缩略预览。

### 第七轮补充

- 缩略预览左上角是小房子图标（主页，回项目列表）；Agent 分页左上角是「‹」（回缩略预览）。
- 底部导航栏三项都有内联 SVG 图标；Agent 是更大的渐变胶囊，始终强调，未读角标照旧。

## 第八轮：底部导航栏比例

- 三项一样大（同宽同高、图标在上文字在下、字号和图标尺寸一致）。（第九轮补充改定：选中样式三项完全一致；只在未选中时 Agent 图标带圆形底，见下。）

## 第九轮：冲突合并改成顶栏下的横条

- 舞台右上角不再有冲突合并按钮；顶栏正下方是「冲突横条」：左边警示图标 + 「2 处改动待合并，其中 1 处有冲突」（数字跟着数据走），右边「处理」按钮打开冲突合并面板。三个分页和编辑状态都显示；全部处理完横条收起，画面仍居中、底部轨道仍贴底。成员按钮仍在舞台右上角。

### 第九轮补充：Agent 的强调

- 选中（当前分页）的样子三项完全一致：青蓝色图标 + 加粗文字，没有底、边框或阴影。
- 只在「未选中」时 Agent 的图标带圆形底（青蓝→酱紫渐变、白色图标）；选中时去掉圆形底。三项仍是 113×46，图标区、文字基线一致。未读角标在圆的右上方。

### 第九轮追加

- 缩略时间轴里点转场 ◇ 和点缩略卡是同一个动作：原地选中（◇ 显示选中圈），不切分页、不进编辑状态；再点一次或点空白处取消。选中转场后子导航栏是「引用、时长·强度、换转场、删除」；时长·强度打开调整面板，换转场打开卡片库转场分类（点一张替换当前的），删除需确认。转场和缩略卡同一时间只能选中一个。想细调就自己点底部导航栏的「时间轴」。没有转场的 ＋ 标记照旧打开卡片库转场分类。
- 全局深色细滚动条：`:root` 里的 `--sb-thumb` / `--sb-thumb-hover` 变量 + `scrollbar-width: thin; scrollbar-color` + `::-webkit-scrollbar` 兜底（宽高 5px、轨道透明、圆角滑块、无箭头、角落透明），底部面板、Agent 对话、完整时间轴（含横向滚动条）都生效；缩略时间轴、工具栏等本来隐藏滚动条的地方保持隐藏。

## 设计规则

配色（颜色都定义在 `:root` 的变量里，`:root` 之外不写硬编码颜色；素材示意、舞台画面内容、颜色选择器的色块除外）：

- **青蓝 `--accent`** 是唯一的交互强调色：选中、当前、主按钮、焦点、开关打开、进度、播放头。
- **酱紫 `--plum`** 只标「这是 Agent / 卡片类内容」的身份，不表示选中。现在用到的地方：项目卡片上的「Agent 在改」、调整面板里的卡片类型标签、成员里 Agent 的头像、对话里的「Agent 操作」标签、舞台上的「Agent 正在改」、时间轴里卡片 / 转场片段的底色、缩略时间轴里的转场标记 ◇、未选中时底部导航栏 Agent 图标的圆形底渐变。
- **警示 `--warn`** 只给冲突、静音这类提醒；**危险 `--danger`** 只给删除、未读角标；**成功 `--ok`** 给完成。

选中态只有两类（加一个例外）：

1. 标签 / 分段 / 小按钮：青蓝淡底 + 青蓝字（素材库分类 `.seg`、创造力 `.level`、Agent 对话标签 `.atab`，子导航栏按下时）。
2. 卡片 / 块 / 片段：青蓝边框（缩略卡 `.mblock`、转场 ◇、时间轴片段 `.clip`、素材 / 卡片 `.tile`、选剪辑 `.crow`）。色块选择器本身就是颜色，选中用白边。
3. 例外：底部导航栏当前项只用青蓝色图标 + 加粗文字，不加底，三项完全一致；只有未选中时 Agent 的图标带圆形底。

圆角四档（`--r-s` 6 / `--r-m` 10 / `--r-l` 18 / `--r-pill` 999，手机壳外框 `--r-shell` 单列）；字号五档（`--fs-xs` 10 / `--fs-s` 11 / `--fs-m` 12 / `--fs-l` 14 / `--fs-xl` 16）。图标一律用内联线性 SVG（描边 1.8、圆角端点，颜色走 `currentColor`）。

## 第十轮：子导航栏统一、时间轴缩放

- 子导航栏：缩略预览和时间轴共用同一个组件（`.subnav`），高度 66、按钮 58 起宽、图标 20、字 11；没选中时两处都是 视频 | 图片 | 音频 | 剪辑 | 卡片 | 文字；选中时第一个是「引用」。
- 时间轴缩放：完整时间轴下方一行有「−」「＋」「适应宽度」和「起点」「终点」对齐按钮。每秒像素在 6～120 之间，「−」「＋」每次约 1.25 倍，以播放头为中心；到上下限按钮禁用；进入时间轴默认「适应宽度」。双指捏合：用 Pointer Events 记录两个手指，距离变化 = 比例变化，以两指中点为中心；捏合时不会拖动、选中、移动播放头。刻度间隔随比例自适应（0.5s … 5 分钟一格），文字不重叠。
