# 手机版 UI 演示稿：名词表

演示稿里用到的名词，以后新名词也记在这里。

| 名词 | 意思 |
|---|---|
| 缩略卡 | 手机版默认编辑页底部「缩略时间轴」里的一张卡，代表主要内容里的一段；各卡等宽，卡上标该段时长。点缩略卡不进入编辑，只把预览跳到这一段开头；长按再拖可以换顺序。 |
| 缩略时间轴 | 默认编辑页底部那一条由缩略卡排成的轨道。不按真实时长缩放，标题行写总时长（例如「3 段 · 共 00:24」）。贴着底部工具栏，在播放条下面。 |
| 主要内容 | 缩略时间轴里放的那几段。演示稿里先写死为视频主轨的几段；怎么自动判断见 `index.html` 里 `mainClips()` 的 TODO。 |
| 分页 | 屏幕最底部的一排切换项：「剪辑」「时间轴」。点「剪辑」选一个剪辑；点「时间轴」展开完整时间轴。 |
| 完整时间轴 | 点底部分页「时间轴」后出现的时间轴：按时间缩放、有刻度、多轨、播放头、选中片段后两端有手柄，底部是选中那一项的工具。叠加内容（文字、字幕、卡片、音乐）从这里选中和编辑。顶部「✕ 退出 / ✓ 完成」退回默认布局（✕ 放弃本次改动）。 |
| 叠加内容 | 不在主轨上的内容：文字、字幕、卡片、转场、音乐。 |
