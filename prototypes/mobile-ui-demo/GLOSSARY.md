# 手机版 UI 演示稿：名词表

演示稿里用到的名词，以后新名词也记在这里。

| 名词 | 意思 |
|---|---|
| 缩略卡 | 手机版「缩略预览」页底部「缩略时间轴」里的一张卡，代表主要内容里的一段；各卡等宽，卡上标该段时长。点一下 = 选中（白色高亮边框，不进入编辑）；点缩略时间轴以外的任何地方 = 取消选中；先选中，再长按这张卡拖动 = 换顺序；没选中时按住拖动一律是滚动缩略时间轴（同时改当前时间）。 |
| 缩略预览 | 底部导航栏上的分页之一，就是默认布局：预览居中、播放条、缩略时间轴、工具栏（视频、图片、音频、剪辑、卡片、文字）。另两个分页是「时间轴」「Agent」。 |
| 当前帧标记 | 缩略时间轴正中固定的一条竖线。缩略卡在它下面滚动：播放时自动滚动，竖线对准的就是当前帧；暂停时竖线也在。手指按住缩略时间轴左右拖动 = 滚动缩略时间轴 = 调整当前时间。卡等宽，所以竖线落在某张卡内的位置按卡内比例换算成时间。 |
| 缩略时间轴 | 「缩略预览」页底部那一条由缩略卡排成的轨道。不按真实时长缩放，标题行写总时长（例如「3 段 · 共 00:24」）。贴着底部工具栏，在播放条下面。 |
| 主要内容 | 缩略时间轴里放的那几段。演示稿里先写死为视频主轨的几段；怎么自动判断见 `index.html` 里 `mainClips()` 的 TODO。 |
| 底部导航栏 | 屏幕最底部的一排，三个分页：「缩略预览」「时间轴」「Agent」，每项有图标，当前的图标和文字一起高亮；「Agent」是更大的青蓝→酱紫渐变胶囊，始终强调。 |
| 分页 | 底部导航栏上的一项，点一下切到对应的页面。 |
| 子导航栏 | 底部导航栏之上一层的按钮行。缩略预览里就是视频、图片、音频、剪辑、卡片、文字那一行（可横向滑动）；点选一张缩略卡后，最前面多出「引用」按钮，取消选中后消失。完整时间轴里对应的是选中片段的工具行。 |
| 引用 | 选中一项后，把它带进 Agent 对话的按钮。点了以后切到「Agent」分页，输入框上方带着这一项的引用标记（例如「@ 沙滩奔跑.mp4」），接着打字就是在问 Agent 怎么改这一项；发送后消息上也显示这个标记。缩略预览里在子导航栏最前面，完整时间轴里紧跟在「分割」后面。 |
| 完整时间轴 | 点底部分页「时间轴」后出现的时间轴：按时间缩放、有刻度、多轨、播放头、选中片段后两端有手柄，底部是选中那一项的工具。叠加内容（文字、字幕、卡片、音乐）从这里选中和编辑。手指在空白处按住左右拖 = 横向滑动时间轴（播放头不动），点空白处 = 取消选中，点或拖刻度尺 = 移动播放头。顶部「✕ 退出 / ✓ 完成」退回缩略预览（✕ 放弃本次改动）。 |
| 叠加内容 | 不在主轨上的内容：文字、字幕、卡片、转场、音乐。 |
| 底部面板 | 从屏幕底部弹出的面板：素材库、卡片库、选剪辑、调整、冲突合并、成员、导出。标题和分类标签固定在上面，内容区上下滑动（滚到头不带动后面的页面）。按住顶部横杠或面板头部拖：往下拖过一定距离 = 关闭，往上拖 = 展开到接近全屏，松手回弹到最近的一档（关闭 / 正常 / 展开）。 |
| 主页 | 项目列表页。缩略预览左上角的小房子图标回到这里；Agent 分页左上角是「‹」，回缩略预览。 |
