# 手机版 UI 演示稿：名词表

演示稿里用到的名词，以后新名词也记在这里。

| 名词 | 意思 |
|---|---|
| 缩略卡 | 手机版「缩略预览」页底部「缩略时间轴」里的一张卡，代表主要内容里的一段；各卡等宽，卡上标该段时长。点一下 = 选中（白色高亮边框，不进入编辑）；点缩略时间轴以外的任何地方 = 取消选中；先选中，再长按这张卡拖动 = 换顺序；没选中时按住拖动一律是滚动缩略时间轴（同时改当前时间）。 |
| 缩略预览 | 屏幕最底部分页之一，就是默认布局：预览居中、播放条、缩略时间轴、工具栏（视频、图片、音频、剪辑、卡片、文字）。另两个分页是「时间轴」「Agent」。 |
| 当前帧标记 | 缩略时间轴正中固定的一条竖线。缩略卡在它下面滚动：播放时自动滚动，竖线对准的就是当前帧；暂停时竖线也在。手指按住缩略时间轴左右拖动 = 滚动缩略时间轴 = 调整当前时间。卡等宽，所以竖线落在某张卡内的位置按卡内比例换算成时间。 |
| 缩略时间轴 | 「缩略预览」页底部那一条由缩略卡排成的轨道。不按真实时长缩放，标题行写总时长（例如「3 段 · 共 00:24」）。贴着底部工具栏，在播放条下面。 |
| 主要内容 | 缩略时间轴里放的那几段。演示稿里先写死为视频主轨的几段；怎么自动判断见 `index.html` 里 `mainClips()` 的 TODO。 |
| 分页 | 屏幕最底部的一排切换项：「缩略预览」「时间轴」「Agent」，当前的高亮。 |
| 完整时间轴 | 点底部分页「时间轴」后出现的时间轴：按时间缩放、有刻度、多轨、播放头、选中片段后两端有手柄，底部是选中那一项的工具。叠加内容（文字、字幕、卡片、音乐）从这里选中和编辑。手指在空白处按住左右拖 = 横向滑动时间轴（播放头不动），点空白处 = 取消选中，点或拖刻度尺 = 移动播放头。顶部「✕ 退出 / ✓ 完成」退回缩略预览（✕ 放弃本次改动）。 |
| 叠加内容 | 不在主轨上的内容：文字、字幕、卡片、转场、音乐。 |
