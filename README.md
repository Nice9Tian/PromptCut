# PromptCut

> Agent 驱动的云原生视频协同平台 —— 面向视频工程的「Figma + Cursor」

PromptCut 是一个 AI 原生的多端协同视频剪辑与动效生成平台。它打破传统视频软件（Premiere、剪映等）封闭、算力只能在本地的限制，把**底层代码生成**、**异构计算渲染**和**多人多端协同**放进同一个工作空间。

## 核心理念

| | |
|---|---|
| **资产原子化** | 一切特效与功能都以「卡片（Card）」为基本单位，卡片的物理形态完全是代码 |
| **双轨驱动** | 人类用户用传统时间轴剪辑；云端 Agent 通过标准 MCP（Model Context Protocol）接口深度介入或接管 |
| **算力分离** | 低配设备调参，高配设备秒渲染 |
| **Web 核心优先** | 在线浏览器模式的代码是绝对核心，各平台外壳延后 |

## 1. 系统架构与多端协同

采用非对称算力分离 + 多端实时协同（类似 Miro / Figma 的同一空间工作流）的云原生架构，解决复杂动效在移动端算力不足的问题。

```
┌──────────────────────────┐        指令 / 参数         ┌──────────────────────────┐
│   轻量编辑端（控制节点）   │ ─────────────────────────▶ │  重算力端（预渲染节点）   │
│  手机 / iPad 浏览器或套壳  │                            │  高性能 PC / 云端工作区   │
│  加载 UI · 解析卡片参数    │ ◀───────────────────────── │  挂载渲染引擎 · 输出画面  │
└──────────────────────────┘     云端快照 / 按拍换快照    └──────────────────────────┘
                                                                     ▲
                                                                     │ MCP
                                                          ┌──────────┴──────────┐
                                                          │  云端 Agent 工作区   │
                                                          └─────────────────────┘
```

- **重算力端（预渲染节点）**：高性能桌面 PC 或云端 Agent 专属工作区。挂载底层渲染引擎，接收工程状态变化并实时输出高规格画面。
- **轻量编辑端（控制节点）**：手机 / iPad（浏览器或套壳）。加载 UI、解析卡片参数、下发修改指令。
- **云端自治工作区（Cloud Workspace）**：借鉴 Claude Cowork 的理念，Agent 拥有独立的云端环境。用户甚至不用打开本地电脑，只靠对话指令就能让 Agent 在后台完成素材组装、特效生成与预渲染。

## 2. 渲染管线与动态路由

项目基于纯 Web-Native 浏览器架构，核心渲染层内置一套「动态渲染路由」，在设备算力与网络带宽之间取得平衡。

### 2.1 卡片的物理形态

完全拥抱前端标准生态，不用 Python / AE 脚本，保证跨端兼容。

| 技术栈 | 负责内容 |
|---|---|
| **DOM / 前端框架**（Remotion / HTML / JS） | 复杂排版、UI 动画、文字动效 |
| **WebGL / WebGPU**（GLSL 着色器） | 像素级图像处理、达芬奇级滤镜调色、光锥与玻璃质感等高级 3D 材质 |

### 2.2 动态渲染路由

系统按卡片的算力消耗评级自动分发渲染任务：

| | 轻渲染卡片 · 端侧前台管线 | 重渲染卡片 · 预渲染推流管线 |
|---|---|---|
| **场景** | 文字动画、UI 动效、基础调色（LUT 查表、亮度/对比度） | 高级 3D 材质、复杂光影特效（单帧渲染耗时 > 播放间隔） |
| **机制** | 直接用轻量设备的浏览器 DOM 或本地 GPU 实时运算播放 | 路由到高性能 PC 或云端节点预渲染，完成后以「云端快照」或「无流按拍换快照」推送到移动端 |
| **收益** | 极致跟手，零网络带宽消耗 | 严格控制触发条件，避免移动端看「直播」导致带宽过载 |

## 3. AI 大脑与创造力引擎

Agent 的角色从「辅助工具」升级为「主程」与「技术美术」。系统内置可调节的**创造力阈值（Creativity Engine）**：

- **低阈值 · 稳健模式（填空题）**：Agent 作为匹配师与调参师，检索内置的 JS / GLSL 模板库，准确理解提示词并修改对应参数，保证工业生产的稳定。
- **高阈值 · 探索模式（简答题）**：Agent 切换为主程，释放代码生成能力，从零编写 WebGL / 着色器代码，创造独一无二的高阶视觉特效。

## 4. UI / UX 设计规范

遵循 Microsoft Fluent Design（Flat 2.0 / Dark Mode Studio UI）的现代深色生产力工具规范。

- **主题色彩**：高饱和度青蓝色（Cyan-Blue）× 低饱和度酱紫色（Purplish-Magenta）
- **整体风格**：全面圆角，极简、现代

### 4.1 双模式交互

**传统模式（Full UI Mode）**

类似剪映 / Premiere。点按两侧分页栏展开、收起、切换菜单，在完整时间轴上手动剪辑。

**SKILL 悬浮窗模式（Agent 托管模式）**

外部大模型（如 Codex / Claude）通过 MCP 端口调用时触发。

- **窗口形态**：收缩为右上角悬浮窗，左上角带图钉（默认始终置顶），可点击放大为完整窗口。
- **迷你时间轴**：悬浮窗内置可拖动、可播放的迷你时间轴。
- **下钻预览**：底部展开按钮，点击后在主预览窗下方额外显示「Agent 修改预览窗口」（与 AI 菜单中的预览一致）。
- **通讯整合**：两侧菜单可显示桌面端 Agent 的操作日志与详细修改预览；消息框不设传统发送按钮，改为居中的「回到 Claude（ChatGPT）对话」按钮，形成闭环。

## 5. 跨端部署与演进路线

采用「Web 核心优先，壳架构延后」的策略，不依赖特定平台。

**当前主力阵列**

| 端 | 定位 |
|---|---|
| 桌面浏览器 | 在线版 / 全功能 |
| 手机浏览器、iPad 浏览器 | 轻量控制端，低内存档 |
| 桌面版 APP | 本地模式，内嵌预渲染进程 |

**后台架构与 Agent 环境**

- 所有在线模式共享底层机制：后台 iframe 预渲染、云端快照、无流按拍换快照。
- Agent 服务端与预渲染进程（Agent / Full 模式）定向适配 Windows、Linux、Ubuntu。

**未来扩展阵列**

- iPad APP、手机 APP（iOS / Android 壳，复用现有 Web 核心；一期暂不开发）。
