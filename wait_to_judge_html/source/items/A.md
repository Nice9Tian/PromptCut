# 云端 Agent 一块（编号前缀 A）：〔裁〕逐条待审清单

调研日期 2026-10-21，只读（没改仓库、没起服务、没开浏览器）。范围：`docs/semantics/product/agent.md`、`mechanism/agent.md`、`workflow/production.md` 里的〔裁〕；`docs/plan/three-versions-rulings.md`「仍待用户审」表；`docs/reports/REPORT-018.md` 第 5 节；2026-10-17 以后与云端 Agent 有关的报告里标〔裁〕或写明「请用户定」、没写进语义、仍然生效的做法。

先说几个全文反复出现的词，后面不再逐条解释：
- **任务进程 / 任务槽**：云端 Agent 每接一条任务，就在云节点上起一个独立进程专门跑它；节点上有 6 个固定的「槽」，同时最多跑 6 条任务。
- **主服务**：云节点上常驻的 Agent 服务，对网页开接口、收消息、转事件，自己不跑任务。
- **文档服务 / 账本**：保存项目真身和权限记录的服务；「账本」是它里面记权限、对话、任务状态的那张表。
- **围栏 / 结清**：围栏 = 文档服务下的「强制停止」指令（用户点停止、切私有、被踢都是围栏）；结清 = 一条任务收尾后，文档服务确认它真的停了、名额让出来。
- **反向通道**：云端 Agent 没有界面，要动用户的播放头之类，只能经文档服务让用户的网页替它做。
- **预渲染 / 轨道流 / 重卡**：重卡 = 实时算不动、需要提前渲成视频的卡片；预渲染 = 提前渲；轨道流 = 渲出来给预览播放用的那条视频。
- **成本记录**：成员的网页测出每张卡「单帧要算多久」，写进文档服务共享，用来判一张卡是不是重卡。

排序：待审（二级在前、三级在后）→ 已审 → 已失效。每条状态、级别、依据都写在块首。

### A02 空闲时排第一的消息不算排队

- 状态：待审

### A05 额度用完发消息当场被拒
